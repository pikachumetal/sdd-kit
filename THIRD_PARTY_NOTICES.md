# Avisos de terceros

Las fuentes de las que el kit copia texto o código (tipo «copia») o toma ideas (tipo «concepto»), con la versión de la que sale cada pieza: en una copia, la que se copió; en un concepto, la última revisada. La tabla de «Fuentes» la genera `moon run kit:notices` desde [`upstream.json`](upstream.json), el registro único de fuentes, igual que el `NOTICE` de cada skill con copias, que viaja con la skill y lleva el texto de la licencia; un test falla si no coinciden. `moon run kit:upstream` compara cada entrada con el último tag de su fuente, solo en sus rutas.
