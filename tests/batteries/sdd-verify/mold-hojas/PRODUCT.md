# Producto — hojas

Hojas de cálculo de facturación para el equipo de administración de una gestoría.

## Product Purpose

Aplicación web interna de una gestoría: la usan cinco personas de administración para preparar y seguir las facturas de sus clientes. La desarrollan dos personas.

## Terminology

- **Hoja**: un documento con una rejilla de celdas (A1, B1…). _Evitar_: sheet.
- **Factura**: un documento con número, cliente, importe y estado (borrador, emitida, cobrada). _Evitar_: invoice.
