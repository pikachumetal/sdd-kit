# Migración a v2.3.5 — el documento heredado sale

Aplica a cualquier proyecto con `.docs/sdd/legacy.md`. Desde la v2.3.5 su contenido vive en las capacidades y el fichero sobra.

1. **Documento heredado.** Si existe `.docs/sdd/legacy.md`, bórralo con `git rm .docs/sdd/legacy.md`. Si no existe, el paso se salta y lo dices.
2. **Marcador.** Escribir en `.docs/sdd/sdd-kit.json` `"version": "2.3.5"`, el `channel` y `"updated": "<hoy>"`, fusionando: las demás claves se quedan como están.

**Escribe**: `sdd-kit.json` → `version`, `channel`, `updated`.

## Verificación

- `Test-Path .docs/sdd/legacy.md` → `False`.
- `.docs/sdd/sdd-kit.json` declara `"version": "2.3.5"` y conserva el resto de sus claves.
