## Spec 0011 — Anular reservas de otros

🦆 Hoy cualquiera puede anular cualquier reserva. Con este cambio solo el responsable de sala podrá hacerlo: si pide anular la reserva de Ana en la sala Norte del lunes, queda anulada y se confirma. Si lo pide un cliente, recibe «solo el responsable de sala puede anular» y la reserva sigue activa. El listado de anuladas pasará a decir quién anuló: «Norte lun — anulada por responsable». El rol no sale de un usuario, porque la app no tiene usuarios: se indica al anular, con una opción nueva.
