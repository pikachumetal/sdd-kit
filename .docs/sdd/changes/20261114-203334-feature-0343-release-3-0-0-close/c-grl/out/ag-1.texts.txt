## 🦆 Qué cambia

Hoy, si la sala que quieres está reservada, nada recuerda que la querías. Con esto:

- `esperar Norte lun 10:00-12:00` responde `Norte ocupada lun 10:00-12:00: apuntada en la lista de espera`.
- `espera` te enseña la lista.
- `dejar-espera Norte lun 10:00-12:00` quita una entrada.

La lista se guarda en `espera.json`. Cada comando del CLI es un proceso nuevo, y en memoria la lista se perdería entre un comando y el siguiente. Cuando se cancela una reserva, la lista **no** actúa sola: eso queda fuera de esta feature.

2. **Qué es la lista**: combinaciones sala + día + franja ocupadas que quieres. Sin posiciones ni nombres, porque lo usas solo tú.
3. **Comandos**: `esperar`, `espera` y `dejar-espera`, con los textos exactos en la spec. Elegí `dejar-espera` para no chocar con `cancelar`.
