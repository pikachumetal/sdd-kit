# Spec — Lista de espera para salas ocupadas

🦆 Hoy, si pides una sala que ya está ocupada, la herramienta no hace nada útil. Con esto, `salas reservar Norte lun 10:00-12:00` (ocupada) te contesta `Norte ocupada lun 10:00-12:00: apuntada en la lista de espera` y la deja apuntada; `salas espera` te enseña lo que tienes apuntado y `salas espera --quitar Norte lun 10:00-12:00` lo borra. Por dentro, es una lista en memoria junto a las reservas que ya existen en `src/app.js`. Ojo: no avisa ni reserva sola cuando la sala se libera, y no sobrevive entre ejecuciones (ver ✋).

Validación: dev-lead — es una orden nueva que usa una persona; lo que sale por pantalla lo tiene que ver él.

- Nuevas: `room-waitlist` — apuntarse en la lista de espera de una sala ocupada, verla y quitarse.
- Modificadas: ninguna.

### Capacidad: `room-waitlist`

#### ADDED — Reservar una sala libre la reserva

- GIVEN la sala Norte ocupada el lun 10:00-12:00 y la sala Sur libre
- WHEN `reservar Sur lun 10:00-12:00`
- THEN responde `reservada Sur lun 10:00-12:00`

#### ADDED — Se apunta en la lista de espera una sala ocupada

- GIVEN la sala Norte ocupada el lun 10:00-12:00
- WHEN `reservar Norte lun 10:00-12:00`
- THEN responde `Norte ocupada lun 10:00-12:00: apuntada en la lista de espera`
- AND no se crea ninguna reserva

#### ADDED — No se duplica una espera

- GIVEN Norte lun 10:00-12:00 ya en la lista de espera
- WHEN `reservar Norte lun 10:00-12:00`
- THEN responde `Norte ocupada lun 10:00-12:00: ya estaba en la lista de espera`
- AND la lista sigue con una sola entrada

#### ADDED — Se consulta la lista de espera

- GIVEN en la lista de espera, por este orden, Norte lun 10:00-12:00 y Norte mar 09:00-10:00
- WHEN `espera`
- THEN responde dos líneas: `Norte lun 10:00-12:00` y `Norte mar 09:00-10:00`
- AND con la lista vacía responde `lista de espera vacía`

#### ADDED — Se quita una espera

- GIVEN Norte lun 10:00-12:00 en la lista de espera
- WHEN `espera --quitar Norte lun 10:00-12:00`
- THEN responde `quitada de la lista de espera: Norte lun 10:00-12:00`
- AND si no estaba, responde `no estaba en la lista de espera: Norte lun 10:00-12:00`
