❓ **¿Dónde sale el CSV?**
El resto de comandos de `run()` devuelven texto que se imprime por pantalla, y los tests comparan ese texto.
1️⃣ **Por pantalla (stdout)**: `exportar Norte` imprime
```
sala,dia,franja
Norte,lun,10:00-12:00
```
y se guarda con `node src/app.js exportar Norte > norte.csv`. Encaja con los demás comandos y se prueba igual; el coste es que quien lo use tiene que redirigir a mano.
2️⃣ **A un fichero**: `exportar Norte` escribe `norte.csv` en la carpeta actual y responde `exportadas 1 reservas a norte.csv`. Es cómodo para abrirlo directamente; el coste es que escribe en disco (y puede pisar un fichero anterior) y hay que decidir nombre y ruta.
