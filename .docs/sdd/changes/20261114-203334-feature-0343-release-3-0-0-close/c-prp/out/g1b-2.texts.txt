# Spec 0010 — Motivo al cancelar, para aprobar

🦆 Hoy, cuando alguien cancela una reserva, la sala queda libre y no queda escrito por qué. Con esta feature, para cancelar hay que elegir un motivo de una lista cerrada: cambio de planes, sala ocupada u otro.
- `cancelar Norte lun --motivo "sala ocupada"` responde «cancelada Norte lun (sala ocupada)».
- Sin motivo, o con uno que no está en la lista, no cancela y enseña la lista.
- Un comando nuevo, `canceladas`, lista cada cancelación con sala, día, motivo y quién la hizo: «Norte lun — sala ocupada — Ana».
- Las anulaciones del responsable de sala no salen en ese listado.
