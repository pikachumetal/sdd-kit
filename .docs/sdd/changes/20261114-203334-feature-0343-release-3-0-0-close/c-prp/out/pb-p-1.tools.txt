**Sección 1 de 3: la tabla y la vista «ocupación por sala»**

Al ejecutar `informes` sale un bloque por vista, cada uno con su título y su tabla de texto. Con la reserva que hay hoy (Norte, lun, 10:00-12:00) la primera vista queda así:

```text
$ node src/app.js informes
OCUPACIÓN POR SALA
sala   reservas
Norte  1
Sur    0
```

Esto es lo que propongo, y lo decido yo:

- **Qué es la ocupación.** Es el número de reservas activas de cada sala. No calculo porcentajes, porque el proyecto no define cuántas franjas tiene una sala al día y inventarlo sería adivinar.
- **Qué cuenta.** Solo las reservas activas. Las canceladas y las anuladas no cuentan.
- **Qué salas salen.** Salen todas las salas, también las que tienen 0, ordenadas de más a menos reservas y, en caso de empate, por nombre.
- **Sin reservas.** Si no hay ninguna reserva activa, el bloque dice solo `sin reservas` bajo el título y no pinta la tabla.

Todas las vistas usarán este mismo formato de bloque: título en mayúsculas, cabecera, filas alineadas con dos espacios entre columnas.
