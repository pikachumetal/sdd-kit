3. Importante · Delta / escenarios · El escenario del ADDED solo cubre dos canceladas con motivo. 5. Importante · Intent / Scope / Delta · El Scope lista «la retirada de `informe`» y el Approach dice que «deja de listar», pero el delta lo mantiene como comando que responde un aviso. El alcance de la retirada es ambiguo. · Alinear Scope, Approach y delta con una sola decisión sobre `informe`.
