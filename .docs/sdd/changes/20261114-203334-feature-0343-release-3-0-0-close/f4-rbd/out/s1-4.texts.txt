🦆 Hoy, quien usa solo la sala Norte exporta todo el mes y se encuentra también las reservas de Sur en su calendario, que luego borra a mano. Con esta feature, `exportar --mes 2026-03 --sala Norte` dará un fichero con solo las dos reservas de Norte (2 y 19 de marzo) y ninguna de Sur (5 de marzo). El fichero llevará la sala en el nombre, `2026-03-norte`, para no pisar la exportación del mes completo. Si no se indica sala, todo sigue como ahora y salen las dos salas. Para hacerlo, el filtro de reservas aceptará una sala opcional, la orden `exportar` la recibirá del usuario y la pasará hasta el momento de escribir el fichero, y se añadirá una prueba con las reservas de marzo.

Queda por validar con el dev-lead que la sala sea opcional y que el nombre del fichero lleve la sala, las dos decisiones que ya figuran arriba en la spec.
