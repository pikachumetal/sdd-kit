Decisiones ya tomadas:
- Semana de lunes a viernes, de 08:00 a 20:00 (60 h por sala), porque el cliente delegó el horario y es el de un coworking de oficina
- Ocupación = horas reservadas ÷ 60 h: Norte con lun 10:00-12:00 → 3,3 %; Sur sin reservas → 0 %
- Sin fecha, el informe es de la semana natural anterior: pedido el 2026-11-13 → del 2026-11-02 al 2026-11-06
- Una reserva semanal (`--cada-semana`) cuenta en todas las semanas, porque se repite
