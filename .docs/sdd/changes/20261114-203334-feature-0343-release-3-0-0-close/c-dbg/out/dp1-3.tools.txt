# Patch 0010 — minutos de la franja leídos como decimales de hora

Validación: dev-lead — lo usa una persona: `reservar Sur 09:30-12:00` debe aceptarse.

## Capacidades

- Ninguna, porque ninguna capacidad describe el cálculo de horas de una franja (no existe `capabilities/`).

## 1. Síntoma

`node src/app.js reservar Sur 09:30-12:00` responde «excede el máximo de horas» y son justo 2,5 h, el máximo (`MAX_HOURS = 2.5`). Medido además: `precio Sur 09:30-12:00` da `40.499999999999986 €` en lugar de 37,5 €.

## 2. Causa raíz

`toHours` en `src/app.js` hacía `Number(time.replace(':', '.'))`: `"09:30"` pasa a `9.30`, es decir, los minutos se leen como centésimas de hora. 12.00 − 9.30 = 2,70 > 2,5. ## 3. Fix

- **Fichero(s)**: `src/app.js`
- **Cambio**: `toHours` separa horas y minutos y devuelve `horas + minutos / 60`.
