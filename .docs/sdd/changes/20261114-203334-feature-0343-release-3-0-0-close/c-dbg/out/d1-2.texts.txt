## Causa raíz

El hook `.githooks/pre-commit` hereda `GIT_INDEX_FILE` de `git commit`. Con esa variable, su `git worktree add` no puede crear el worktree temporal.

Cuando git ejecuta un hook de pre-commit, exporta `GIT_INDEX_FILE` con una ruta relativa, `.git/index`. Los `spawnSync('git', …)` del hook heredan esa variable.

- **Dónde falla:** `git worktree add --detach .git/hook-check HEAD`, en la línea 8 del hook. El comando intenta crear el índice del worktree nuevo en `.git/hook-check/.git/index.lock`. Ahí no existe ese directorio todavía, y git aborta.
- **Cómo lo comprobé:** ejecutado a pelo, el hook sale con 0. Con `GIT_INDEX_FILE=.git/index` falla con este error y sale con 1:

  ```
  fatal: Unable to create '…/.git/hook-check/.git/index.lock': No such file or directory
  ```

- **Qué no es:** no tiene que ver con `notas.txt`, ni con su contenido. Cualquier commit falla igual. La deuda (`debt.md`) no recoge este fallo.
- **Por qué no sale en la terminal:** `GIT_INDEX_FILE` solo existe dentro de un commit. En una terminal normal no está definida.

El hook tampoco limpia `GIT_INDEX_FILE`, ni `GIT_DIR` ni `GIT_WORK_TREE`, en ninguno de sus `git`. Con una ruta absoluta el comando no falla, pero ese caso es peor: el checkout escribiría sobre el índice real.
