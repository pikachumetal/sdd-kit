# Spec — Exportar solo las reservas de una sala

## Decisiones que he tomado yo — valida estas

1. El parámetro de sala es opcional: sin él, la exportación sigue sacando las dos salas.
2. El fichero lleva la sala en el nombre para no pisar la exportación del mes completo.

## Intent

=== RESULTADO (4 turnos, 0.0858223 $)
🦆 Hasta ahora, el socio que solo usa la sala Norte se llevaba a su calendario también las reservas de Sur y tenía que borrarlas a mano. Con esta feature podrá pedir la exportación de una sola sala: con `exportar --mes 2026-03 --sala Norte` saldrá un fichero con las dos reservas de Norte (2 y 19 de marzo) y ninguna de la del 5 de marzo en Sur. Para lograrlo, el comando acepta una sala opcional y deja pasar solo las reservas de esa sala al preparar la exportación. Si el socio no indica sala, todo sigue igual: salen las dos salas. El fichero lleva la sala en el nombre (`2026-03-norte`), así que no pisa la exportación del mes completo.

Las dos decisiones que he tomado yo (sala opcional y sala en el nombre del fichero) quedan marcadas en la spec para que el dev-lead las valide.
