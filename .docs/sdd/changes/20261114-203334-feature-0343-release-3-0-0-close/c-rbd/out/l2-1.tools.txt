## Users

- **Socio del coworking**: reserva salas y se lleva sus reservas a su calendario.
- **Responsable del coworking**: mantiene la herramienta; hace de dev-lead: decide qué entra y aprueba las specs, pero no lee el código.
- **Dev**: desarrolla la herramienta.

## Product Purpose

Reservar las dos salas de reuniones del coworking desde la terminal y llevarse las reservas de un mes al calendario de cada uno (Google Calendar, Outlook) con un fichero que se importa.

## Capabilities and Constraints

- **Es**: reservar, cancelar y exportar las reservas de un mes.
-

=== RESULTADO (6 turnos, 0.1030417 $)
Here is how the March export travels, using the real flow in the code.

**Example:** you ask for the export of March 2026. The coworking has four reservations that month. One of them is cancelled.

1. **You ask.** You run the export command and give it the month, "2026-03".
2. **The tool reads the month.** It passes the month on to the part that builds the export.
3. **It loads all reservations.** It reads the saved list of reservations, for every month. The list holds five entries: four in March and one in April.
4. **It keeps the ones you need.** It drops April and the cancelled reservation (Norte, 12 March, 09:00-10:00). Three remain. It puts them in date and time order: Norte 2 March, Sur 5 March, Norte 19 March.
5. **It turns each reservation into a calendar entry.** Each entry is titled "Sala Norte" or "Sala Sur" and has a start and an end time. The coworking keeps its own time, two hours ahead of UTC. Calendars expect UTC, so the tool converts the times. The Norte reservation on 2 March, 10:00-12:00, becomes 08:00-10:00 UTC. Your calendar then shows it at the right local time.
6. **It wraps the entries in one calendar file.** The three entries go inside one calendar envelope, in the standard format that Google Calendar and Outlook both read.
7. **It saves the file.** It creates the exports folder if it is missing. It saves the file there under the month's name, "2026-03". If you export March again, the new file replaces the old one.
8. **It tells you where the file is.** The tool prints the location of the file on screen.

After the tool finishes, you open that file in Google Calendar or Outlook and import it. The three March reservations then appear in your calendar. This step happens outside the tool. The export is a one-time copy, so later changes to reservations do not reach your calendar. You must export and import again.

Some limits you may meet:
- If you give a month with no reservations, you get a valid file with no entries.
- The time conversion uses the coworking's current two-hour offset as a fixed value. It does not adjust for daylight saving changes.
- The roadmap has an "export by room" feature with a spec. The tool does not do it yet: it always exports both rooms.

**Where to look**
