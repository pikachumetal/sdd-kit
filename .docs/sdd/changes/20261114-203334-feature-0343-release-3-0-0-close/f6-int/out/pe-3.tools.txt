## Intent

Hoy no hay forma de sacar las reservas de una sala de la herramienta. El responsable de cada sala las cuadra los lunes en su hoja de cálculo, y ahora tendría que copiarlas a mano. Se quiere un comando que las vuelque a CSV, que se abra bien en la hoja de cálculo (columnas separadas, tilde correcta). Éxito: `salas exportar Norte > norte.csv` produce un fichero que se abre en tres columnas con las reservas de Norte. Fracaso aunque funcione: un export de una sala mal escrita que parezca válido, o un CSV que la hoja abra con todo en una columna.

Pendiente: cómo llega el fichero al responsable (lo hace el dev-lead a mano por ahora).
