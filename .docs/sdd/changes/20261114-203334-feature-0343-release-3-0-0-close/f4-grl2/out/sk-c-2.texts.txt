❓ **¿Cómo se ve cada fila?**
1️⃣ **Número y barra:** una tabla igual que la del listado, con una barra horizontal por fila.
```
Sala    Ocupación
Norte   ███░░░░░░░  30 %
Sur     █░░░░░░░░░  10 %
```
Se lee de un vistazo y se compara a ojo entre salas. Cuesta un poco de CSS y hay que cuidar la versión de 390 px.

```
Sala    Ocupación
Norte   30 %

```

3️⃣ **Número y desglose por día:** una fila por sala, con el porcentaje total y una celda por día (lun a dom).

```
Sur     10 %    ·    ■    ·    ·    ·
```
