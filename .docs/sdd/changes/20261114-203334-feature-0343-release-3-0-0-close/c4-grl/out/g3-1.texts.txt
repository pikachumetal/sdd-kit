1️⃣ **Comando `esperar` que se queda vigilando y reserva solo.**
`esperar Norte lun 10:00-12:00` → `Norte ocupada; esperando…` y, cuando se libera: `Norte libre: reservada lun 10:00-12:00`.
Sustituye tu «mirar libres cada rato» y funciona aunque quien libere la sala no use esta herramienta. A cambio, necesita una terminal abierta (o un proceso en tu servidor) y reserva sin preguntarte.

2️⃣ **Lista de espera que se resuelve al cancelar.**
`reservar Norte lun 10:00-12:00` → `Norte ocupada; en espera (1.º)`. Luego, `cancelar Norte lun` → `cancelada; reservada Norte lun 10:00-12:00 para el 1.º en espera`.
No hace falta proceso vigilando, pero solo salta si la cancelación pasa por esta herramienta.
