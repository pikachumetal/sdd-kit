### Strengths

**Important**
- None.

**Minor**
1. `test/cancel.test.js:96-97` and `:117`. The shared-state dependency is wider than the comment says. The last test (`canceladas…`) also depends on the previous test having cancelled `Norte lun` with "sala ocupada". It fails if run alone (`--test-name-pattern`) or if the tests are reordered.
