## Hallazgos

### 1. El Step 2 de `sdd-worktrees` dice `npm install`, que no instala un workspace de pnpm

- **Qué pasó**: el patch hace que los carriles patch y config nombren el Step 2 de `sdd-worktrees`. Ese paso instala con `npm install` si hay `package.json`. En una copia de la raíz de este repo (`package.json` sin dependencias, `pnpm-workspace.yaml` con `cli/`), `npm install` acabó con «up to date, audited 1 package» y `cli/node_modules` no existía. En el molde del RED (`reservas-deps`, con `fecha: workspace:*`), `npm install` acaba en `npm error code EUNSUPPORTEDPROTOCOL`. En el GREEN, los 4 sujetos usaron `pnpm install`, pero porque el `tech-stack.md` del molde dice «`pnpm install` una vez por worktree»; un proyecto que no lo escriba seguiría el paso al pie de la letra.
- **Fuente**: `skills/sdd-worktrees/SKILL.md:108-110`; `npm install` en PowerShell sobre una copia del scratchpad; `.docs/sdd/specs/20261028-211807-patch-0248-lanes-env-setup/green/out/ws2-1.tools.txt` («`pnpm install` en el worktree, porque `tech-stack.md` usa pnpm»)
- **Dónde en el kit**: `skills/sdd-worktrees/SKILL.md`, Step 2 («Project Setup»), la línea de Node.js
- **Por qué el kit no lo evitó**: el bloque es el texto de superpowers 7.0.0 (Art. IX) y nadie lo midió con un gestor distinto de npm
- **Coste**: 0 en esta sesión; en un proyecto pnpm sin la línea en `tech-stack.md`, el `Cannot find module` que este patch quería evitar (sin respaldo: no medido)
- **Propuesta**: que la línea de Node elija el gestor por el lockfile (`pnpm-lock.yaml` → `pnpm install --frozen-lockfile`, `yarn.lock` → `yarn install --frozen-lockfile`, `package-lock.json` → `npm ci`, si no `npm install`), como cambio del kit sobre la fuente
- **Verificada**: sí — el fallo de `npm install`, reproducido en PowerShell en las dos copias; la propuesta, sin verificar
- **Criterio de aceptación**: GIVEN el molde `reservas-deps` sin la línea de pnpm en `tech-stack.md` WHEN un sujeto sigue el carril patch o el config THEN corre `pnpm install` antes del primer test y no lee `ERR_MODULE_NOT_FOUND` (hoy sin medir: el RED que falta)
