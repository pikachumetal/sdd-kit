- **Feature 0235** — `sdd merge --verify` corre solo lo que se cruza y sin shell. Con un gate `moon run … --affected`, cada pasada (el merge, cada reintento de push y el contraste de un rojo, también en la ida y la vuelta de un hotfix) pregunta a moon (`moon query tasks --affected` con `MOON_BASE`, `MOON_HEAD` y, con `-g`, `MOON_INCLUDE_RELATIONS`) qué tareas toca la rama desde su merge-base y cuáles tocó la base desde `--verified-at`, y corre solo la intersección, con `--affected --base <verificado>`; las demás salen como `verificación: <tarea>: saltada (la base no toca sus inputs)` o `(solo la toca la base)`, sin `--verified-at` corre lo que toca la rama, y con un target o una opción que no se puede cruzar o un `moon query` que falla, también, con `verificación: sin cruce: …`. El contraste de un rojo corre sobre la base los mismos targets, sin `--affected`. El gate se parte en argumentos (las comillas agrupan) y se lanza con el lanzador de `sdd lock run`, sin `pwsh` ni `sh`: un `&&`, `||`, `;`, `|`, `>` o `<` fuera de comillas sale con 2 antes del cerrojo, y un programa que no está lo dice.
