#### Important (Should Fix)
1. **`test/cancel.test.js:93-95` — the `canceladas` test depends on test order.** It expects `Norte lun — sala ocupada`, which only exists because the first test cancelled that booking in the module's shared state. Run on its own (`--test-name-pattern`) or reordered, it fails. `bookings` is a module-level array with no reset.
