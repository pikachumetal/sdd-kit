### Issues

#### Critical (Must Fix)

**1. The REMOVED requirement still runs: voiding still sends the email** — `src/app.js:35`, `src/app.js:16-18`, `src/app.js:6`
- What's wrong: `voidBooking` still calls `notifyByMail(\`anulada ${room} ${day}\`)`, and `notifyByMail` and the exported `outbox` are still there.
- Why it matters: the spec deletes this behaviour («El correo de anulación desaparece»), and it is a decision taken with the dev-lead.

- Gap: `contradicts`. Source: «REMOVED — Las anulaciones se avisan por correo» and the dev-lead's decision «El correo de anulación desaparece».

#### Important (Should Fix)

**2. ADR 0003 is broken: `src/` now imports `node:fs` and writes voided bookings to disk** — `src/app.js:1`, `src/app.js:25-27`, `src/app.js:36`
- What's wrong: `saveVoided()` writes `data/anuladas.json` on every void.
- Why it matters:
  - It fails ADR 0003's Confirmación: «`src/` no importa `node:fs` ni ningún paquete de base de datos».
  - The spec's Scope says «No entra: guardar las anulaciones».
  - It also has a practical effect: `data/` isn't in the repo, so `anular Norte lun --motivo avería` from the terminal throws ENOENT and prints a stack trace instead of the reply. The test only passes because it runs `mkdirSync('data')` first (`test/void.test.js:6`).
- How to fix: remove `saveVoided`, the `node:fs` import, and the `mkdirSync` in the test.
- Gap: `contradicts` (it goes against the ADR and the scope).

**3. The dev-lead's decision is only half covered: `anular-todas` doesn't ask for a reason** — `src/app.js:40-44`, `src/app.js:52`

- Why it matters: decisión del dev-lead cubierta a medias: «Anular pide motivo en las dos vías, `anular` y `anular-todas`» — the rule only covers `anular`, so `anular-todas` with no reason still gets through. The Scope also includes `anular-todas --motivo <texto>`.
- How to fix: pass `reasonOf(params)` to `voidAll`, return «falta el motivo» when it's missing, and store `reason` on each booking. Add tests for both cases.
- Gap: `partial`. Source: the dev-lead's decision and the Scope.
