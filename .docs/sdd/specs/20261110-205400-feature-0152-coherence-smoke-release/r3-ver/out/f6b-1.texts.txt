### Issues

#### Critical (Must Fix)
- **`src/app.js:29`: the `iban` parameter goes through `Math.trunc`.**
  - **What's wrong:** an IBAN is a string such as `"ES91…"`, so `Math.trunc("ES91…")` returns `NaN`. The comment says the value can't have cents, so the parameter is almost certainly an amount that was named `iban`. Either the name is wrong or the wrong field is being truncated.
  - **Failure scenario:** `saveRefund('A1', 'ES9121000418450200051332')` returns `{ room: 'A1', iban: NaN }`.
  - **Fix:** take both values, for example `saveRefund(room, iban, amount)` returning `{ room, iban, amount: Math.trunc(amount) }`. If only the amount was meant, rename the parameter and field to `amount`.

#### Important (Should Fix)
- **`src/app.js:28`: the comment cites `capabilities/refunds.md`.**
  - **What's wrong:** "Code constraints" forbids comments that cite documents, whatever the reason given. The path also goes stale if the document moves.
  - **Fix:** keep the reason and drop the citation: `// El banco rechaza las devoluciones con céntimos`.
  - **Related:** the comment sits above a line that truncates, but it doesn't say why truncating is right rather than rounding. That choice matters for money.
- **`src/app.js:27`: `saveRefund` has no test.**
  - **What's wrong:** it is a new public function, and the task reports show none. A test would have caught the `NaN` above.
  - **Judgement:** Clean Code, "a test for every public method" (possible).
  - **Fix:** add a test for a decimal amount, an integer amount and a negative amount.
  - **Related:** the function validates nothing. A non-number, a negative amount or a missing value passes straight through and can produce `NaN`.
- **`src/app.js:27`: despite its name, `saveRefund` stores nothing.**
  - **What's wrong:** it returns an object and has no side effect, and nothing in the diff calls it. The commit message says "guardar la devolución" (save the refund).
  - **Judgement:** Clean Code, "names reveal intent" (possible).
  - **Fix:** either wire it to storage or rename it, for example `buildRefund`.
