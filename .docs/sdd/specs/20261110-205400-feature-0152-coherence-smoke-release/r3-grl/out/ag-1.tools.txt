# Spec — Lista de espera para salas ocupadas

🦆 Hoy `reservar` solo sabe crear la reserva semanal; si la sala que quieres está ocupada no hay forma de dejar apuntado que la querías. ## Intent

Cuando quiero una sala en una franja y ya está reservada, hoy no puedo dejarlo apuntado. Quiero apuntarme a la espera de esa sala y franja y poder ver después todo lo que tengo apuntado. Éxito: tras `reservar Norte lun 10:00-12:00` con la sala ocupada, `espera` me devuelve `Norte lun 10:00-12:00`. Fracasaría, aunque funcione, si apuntarse alterara `bookings` o rompiera `reservar --cada-semana`.

## Scope

- Entra: `reservar <sala> <día> <franja>` (reserva si libre, lista de espera si ocupada), comando `espera`, sin duplicados.
- No entra: aviso o promoción automática al cancelar, salir de la lista, persistencia entre invocaciones, validar sala, día o franja.

## Approach

- A: array `waitlist` en `src/app.js` junto a `bookings`, dos ramas nuevas en `run` — cuesta casi nada y encaja con el fichero único de `operations.md`; la lista se pierde al acabar el proceso.

- C: módulo nuevo `src/waitlist.js` — separaría una función de dos líneas; `operations.md` fija «un solo fichero de entrada» y no hay más módulos.
- Elegido: A — es lo mínimo coherente con cómo está el código hoy; B queda para una feature propia (decisión 2).

#### ADDED — Reservar una franja libre

- GIVEN apuntada en `Norte lun 10:00-12:00` y después en `Norte mar 09:00-10:00` (ocupada también)
- WHEN `espera`
- THEN responde dos líneas, `Norte lun 10:00-12:00` y `Norte mar 09:00-10:00`, en ese orden
