# Capacidad — bookings

## Propósito

Reservar y cancelar salas.

## Requisitos

### Reservar una sala

- GIVEN la sala Sur libre el lunes a las 10:00
- WHEN se ejecuta `reservar Sur lun 10:00`
- THEN responde «reservada Sur lun 10:00»

### Las salas salen de su módulo

- GIVEN `src/rooms.js` con Norte y Sur
- WHEN se ejecuta `salas`
- THEN responde «Norte, Sur»
