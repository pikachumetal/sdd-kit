#### Minor (Nice to Have)

4. `src/app.js:40-41`: the check for a valid reason is split in two. `readReason` checks that the reason is on the list, while the exported `cancelBooking` only checks that it is truthy. A direct caller could therefore store `cancelBooking('Norte','lun','xyz')`. If `cancelBooking` should own the invariant, move the `CANCEL_REASONS.includes` check into it.
