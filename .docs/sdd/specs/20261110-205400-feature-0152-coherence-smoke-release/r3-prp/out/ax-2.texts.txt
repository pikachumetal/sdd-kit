Terminal:

```
cd <run>\repo
```

1. Cancelar con un motivo válido:

```
node src/app.js cancelar Norte lun --motivo "sala ocupada"
```

→ `cancelada Norte lun (sala ocupada)`

2. Motivo fuera de la lista:

```
node src/app.js cancelar Norte lun --motivo aburrimiento
```

→ `motivo no válido: cambio de planes, sala ocupada, otro`

3. Sin motivo:

```
node src/app.js cancelar Norte lun
```

→ `motivo no válido: cambio de planes, sala ocupada, otro`

4. Listado en un proceso nuevo:

```
node src/app.js canceladas
```

→ `sin canceladas` (a propósito: el motivo solo se ve dentro de un proceso, ver «Sin probar»)

Si no puedes ahora: `Diferir: lo pruebo en <uso más próximo, concreto>, a cargo de <quien valida>`

Dime "validado" o qué paso falla.
