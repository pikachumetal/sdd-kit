❓ **¿Cómo se ve el Estado?**

1️⃣ **Etiqueta con color y texto**
```text
Sala   Día  Franja  Quién  Estado
Norte  lun  10:00   Ana    [ confirmada ]  (verde)
Sur    mar  12:00   Luis   [ pendiente ]   (ámbar)
Norte  mie  16:00   Marta  [ cancelada ]   (rojo/gris)
```
Se distingue de un vistazo y el texto sigue ahí, así que el color no es la única señal. Cuesta unas pocas reglas de CSS en `styles.css`.

2️⃣ **Solo texto**
```text
Norte  lun  10:00  Ana    confirmada
Sur    mar  12:00  Luis   pendiente
Norte  mie  16:00  Marta  cancelada
```
Es lo mínimo y no toca el CSS. Hay que leer cada fila para distinguir los estados.

3️⃣ **Texto más la fila cancelada atenuada y tachada**
```text
Norte  lun  10:00  Ana    confirmada
Sur    mar  12:00  Luis   pendiente
~~Norte  mie  16:00  Marta  cancelada~~   (en gris)
```
Las canceladas se apartan visualmente, pero `confirmada` y `pendiente` quedan iguales. Cambia el aspecto de toda la fila, no solo de la columna que pediste.
