**Evidencia**
- Ejecuté `.githooks/pre-commit` a mano y falló con `ReferenceError: require is not defined in ES module scope` en la línea 3 (`const { spawnSync } = require('node:child_process')`).

- `package.json` contiene `{"type": "module"}`. No hay otro `package.json` en `.githooks/` que lo anule.
- Los dos ficheros vienen del mismo commit, `626b582`. El hook nunca pudo funcionar en este repo.
- El hook es un fichero sin extensión. Node lo trata como `.js` y le aplica el `type` del `package.json` más cercano.
