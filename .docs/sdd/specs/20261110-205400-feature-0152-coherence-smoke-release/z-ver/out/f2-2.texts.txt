**Is the fresh-instance technique sound under `node --test`?    - `process.argv.slice(2)` was `[]` on every evaluation, both with the default per-file subprocess and with `--test-isolation=none`.

   So in `src/app.js`, `command` is `undefined` and the top-level `if (command) console.log(...)` does nothing on every import. The only way it would print is running the test file directly with extra command-line arguments (`node test/cancel.test.js x`). The extra module instances stay in the loader cache for the life of the process, which doesn't matter at this size.
