#### Critical (Must Fix)

**1. The removed requirement «Avisar por correo» still runs.**
- **File:** `src/app.js:18`, which runs `outbox.push({ to: 'responsable', body: \`anulada ${room} ${day}\` })`.
- **What's wrong:** The commit removed the email formatting but not the notice. Every `anular` still puts a message for `responsable` in `outbox`. `salida` then shows it (`src/app.js:29,36`). Input `anular Norte lun` followed by `salida` returns «responsable: anulada Norte lun».
- **Why it matters:**
  - The spec's delta says `REMOVED — Avisar por correo`, the Approach says «`anular` deja de preparar el aviso», and the Intent says «Se quita el aviso».
  - The notice is still prepared and still delivered to the same person. The only change is that it no longer says «correo».
- **How to fix:** Delete line 18. Nothing else writes to `outbox`, so `outbox`, `pending()` and `salida` become dead code for this feature. Leave them to the other axes, or remove them under a separate requirement.
- **Gap:** `contradicts`
- **Comes from:** the spec's `REMOVED — Avisar por correo`, plus the Approach.
