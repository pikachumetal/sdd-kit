❓ **¿Cómo se ve la ocupación de cada sala?**
1️⃣ **Tabla con número y barra.** Es la misma tabla que ya tiene `index.html`, con una barra horizontal en cada fila:
```text
Sala    Ocupación
Norte   ████████░░░░░░░░  50 %
Sur     ███░░░░░░░░░░░░░  20 %
```
Con una barra se comparan las salas de un vistazo. El número exacto sigue ahí, y encaja con el estilo actual de la web.
2️⃣ **Tabla solo con el número.**
```text
Sala    Ocupación
Norte   50 %
Sur     20 %
```
Es lo más simple, pero comparar las salas cuesta más.
3️⃣ **Una tarjeta por sala, con el número grande.**
```text
┌────────┐ ┌────────┐
│ Norte  │ │ Sur    │
│  50 %  │ │  20 %  │
└────────┘ └────────┘
```
Se lee bien en móvil (390x844). Deja de ser «una fila por sala» y se aleja de la tabla del listado.

➡️ **Recomiendo 1️⃣**, porque pides una fila por sala y la barra añade la comparación sin salirse de ese formato ni del estilo de la web. A cambio, la barra necesita algo de CSS nuevo y hay que comprobar que se ve bien en el viewport estrecho.
