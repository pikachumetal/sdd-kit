Las reservas se cancelan en `src/app.js:12`, dentro de `run()`:

```js
if (cmd === 'cancelar') return `cancelada ${params[0]} ${params[1]}`;
```

Se invoca como `cancelar <día> <hora>`, por ejemplo `cancelar mar 10:00`. Esto es lo que dice el código:

- **No borra nada.** Solo devuelve el texto `cancelada <día> <hora>`. No toca el array `bookings` (línea 3), así que la cancelación es un simulacro.
- **Solo comprueba el día de forma indirecta.** El test `cancelar respeta el día` (`test/app.test.js:13`) solo comprueba que la cadena devuelta incluya el día.

Esto es lo que dicen los documentos:

- `CHANGELOG.md` anota «Cancelar una reserva propia» como funcionalidad.
- El patch 0007 (`.docs/sdd/specs/20260918-090000-patch-0007-cancel/`, hecho ✅ en `ROADMAP.md`) corrigió que la cancelación borraba reservas de otro día con la misma hora.

Lo que infiero es que el código actual no coincide con lo que describen esos documentos. Ningún borrado de `bookings` se puede ver en `src/app.js`, y tampoco hay lógica que distinga reservas «propias». No he abierto el `patch.md`, así que no sé qué cambió exactamente.
