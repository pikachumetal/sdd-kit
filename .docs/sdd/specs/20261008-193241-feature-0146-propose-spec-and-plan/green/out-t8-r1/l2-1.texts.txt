Here is the path of a March export, followed through the code. The example is the North room on 2 March, 10:00–12:00.

**Steps**

1. **You ask for it.** You run the export command from the terminal and name the month, for example March (`2026-03`). The command reads the month and passes it on. It does nothing else, and it doesn't check that you gave a month.
2. **The reservations are read.** The tool opens the one file where all reservations are kept and loads every reservation for every month. Your North-room reservation is one of five rows: two rooms, two months, one of them cancelled.
3. **The month is picked out.** The tool keeps only reservations whose day falls in March and drops cancelled ones. The cancelled North reservation on 12 March is lost here. The April reservation is lost too. Your 2 March reservation stays, and the survivors are sorted by day and time.
4. **Each reservation becomes a calendar event.** The tool builds a calendar file with one event per surviving reservation. Your event is titled "Sala Norte", with a start of 10:00 and an end of 12:00.
5. **Times are converted.** The coworking's times are treated as two hours ahead of UTC, the universal reference clock that calendars exchange times in. Your 10:00 becomes 08:00 and your 12:00 becomes 10:00. The conversion always uses +2 hours, so it doesn't change with the season. As written, the times come out without the trailing "Z" that marks UTC. A calendar may therefore read them as local time rather than UTC, and I haven't tested how Google Calendar or Outlook treat that.
6. **The file is saved.** The tool creates the `exports` folder if it's missing and writes the calendar file there, named after the month. It prints where the file is.

**After the steps (outside the code)**

You open that file and import it into Google Calendar or Outlook. The tool does not send it anywhere or keep it in sync. Each export is a snapshot, and it overwrites any earlier export for the same month.

**Where to look**

- Step 1: `src/cli.js`
- Order of the steps: `src/export/index.js`
- Step 2: `src/bookings/repository.js`, data in `data/bookings.json`
- Step 3: `src/export/filter.js`
- Steps 4 and 5: `src/export/ics.js`
- Step 6: `src/export/writer.js`, with the result in `exports/2026-03.ics`
