# Plan de implementación — Salas favoritas

## Decisiones que he tomado yo — valida estas

1. **Contrato de la API, que la spec no fija** — `GET /rooms` devuelve `{id, name, seats, favorite}` con las favoritas de quien manda `X-User` primero y el resto por nombre; `PUT /rooms/:id/favorite` marca y `DELETE /rooms/:id/favorite` desmarca, los dos idempotentes y con respuesta `200 {id, favorite}`. Es salida observable (rutas y campos públicos): la fijo aquí para que la valides antes de despachar, no como ruling.
2. **Sin `X-User`** — el listado sigue funcionando y no marca ninguna; `PUT`/`DELETE` responden 400. Así el listado de hoy no se rompe para quien no manda la cabecera.
3. **Sala inexistente o id no numérico en `PUT`** — 404, sin fila en `favorite_rooms`. `DELETE` sobre algo no marcado no falla (idempotente).
4. **Dos tasks, no tres**: BD + API (Task 1) y web (Task 2). La API entera son ~30 líneas y una migración; partirla en más no da ningún punto donde un revisor rechace una y apruebe la otra.

Revisor final: `opus` + `effort-high`, el techo del kit. **Despachar subagentes necesita tu confirmación de esta asignación** (regla de coste de tu CLAUDE.md).
6. **Ejecución `subagent`**: las dos tasks se pasan un contrato de API entre capas y el revisor por task lo comprueba antes de que la web lo consuma. Coste orientativo: ~2 h de reloj, 2 implementadores + 2 revisores de task + 1 revisor final.

**Goal**: Cada persona marca y desmarca salas favoritas con una estrella, y la lista de salas muestra primero las suyas.

**Architecture**: Una tabla `favorite_rooms (user_name, room_id)` guarda una fila por persona y sala. `GET /rooms` hace `LEFT JOIN` con esa tabla filtrando por `X-User` y ordena por `favorite DESC, name`. La web añade un botón-estrella por sala que llama a `PUT`/`DELETE` y recarga el listado con `rooms.reload()`.

**Tech Stack**: Postgres (migración SQL numerada), Express (handlers en `api/routes/rooms.js`), `node:test`, Angular con `httpResource` y `HttpClient`.

**Spec**: `./spec.md`

**Ejecución**: subagent, porque las dos tasks se pasan un contrato de API entre capas y conviene revisar la primera antes de que la segunda lo consuma; lo pide además el encargo del dev-lead («despachar el implementador de la Task 1»).

```js
import { Router } from 'express';
import { db } from '../db.js';

export const rooms = Router();

const userOf = (req) => req.get('X-User');

rooms.get('/rooms', async (req, res) => {
  const { rows } = await db.query(
    `SELECT r.id, r.name, r.seats, (f.room_id IS NOT NULL) AS favorite
       FROM rooms r
       LEFT JOIN favorite_rooms f ON f.room_id = r.id AND f.user_name = $1
      ORDER BY favorite DESC, r.name`,
    [userOf(req) ?? null],
  );
  res.json(rows);
});

rooms.put('/rooms/:id/favorite', async (req, res) => {
  const user = userOf(req);
  const id = Number(req.params.id);
  if (!user) return res.sendStatus(400);
  const { rowCount } = Number.isInteger(id)
    ? await db.query('SELECT 1 FROM rooms WHERE id = $1', [id])
    : { rowCount: 0 };
  if (!rowCount) return res.sendStatus(404);
  await db.query(
    'INSERT INTO favorite_rooms (user_name, room_id) VALUES ($1, $2) ON CONFLICT DO NOTHING',
    [user, id],
  );
  res.json({ id, favorite: true });
});

rooms.delete('/rooms/:id/favorite', async (req, res) => {
  const user = userOf(req);
  const id = Number(req.params.id);
  if (!user) return res.sendStatus(400);
  if (Number.isInteger(id)) {
    await db.query('DELETE FROM favorite_rooms WHERE user_name = $1 AND room_id = $2', [user, id]);
  }
  res.json({ id, favorite: false });
});
```

```ts
import { Component, inject } from '@angular/core';
import { HttpClient, httpResource } from '@angular/common/http';

interface Room {
  id: number;
  name: string;
  seats: number;
  favorite: boolean;
}

@Component({ selector: 'app-rooms', templateUrl: './rooms.component.html' })
export class RoomsComponent {
  private readonly http = inject(HttpClient);
  readonly rooms = httpResource<Room[]>(() => '/api/rooms');

  toggleFavorite(room: Room) {
    const url = `/api/rooms/${room.id}/favorite`;
    const request = room.favorite ? this.http.delete(url) : this.http.put(url, null);
    request.subscribe(() => this.rooms.reload());
  }
}
```
