# Plan de implementación — Reservas que se guardan y se cancelan

## Decisiones que he tomado yo — valida estas

1. **Modelo y effort**: las dos tasks con `subagent_type: sdd-kit:effort-medium` + `model: sonnet`. Llevan el código casi escrito, pero el implementador tiene que casarlo con los tests y la CLI; Haiku no admite effort y el margen de ahorro es mínimo.
2. **Ejecución**: `subagent`, porque el dev-lead pidió parar justo antes de despachar el implementador de la Task 1. Con solo 2 tasks pequeñas, Native saldría más barato: si prefieres Native, dilo antes de la Task 1.
3. **Ruta del fichero configurable con `SALAS_DATA`**: por defecto `data/reservas.json` (spec); la variable de entorno la usan los tests para no tocar el fichero real. Se lee en cada llamada, no al importar.
4. **`data/reservas.json` va a `.gitignore`**: son datos de ejecución, no código. La carpeta `data/` se crea al guardar.
5. **Salida de `cancelar` al tener éxito**: imprime la reserva cancelada como JSON, igual que `reservar` (`{"room":"Norte","slot":"10-12"}`). La spec no la fija; es salida observable nueva.
6. **`cancelar` valida la franja** con el mismo aviso «Franja no válida…» antes de buscar la reserva (la regla de avisos de la spec lo cubre).
7. **`salas reservas` sin reservas** imprime una línea vacía. Sin ordenar: sale en orden de reserva.
8. **Sin control de fichero corrupto**: un JSON roto hace fallar la CLI con el error de `JSON.parse`. Techo aceptado para una CLI de un solo usuario; se protege si aparece un segundo escritor.
9. **Sin modificar `src/slots.js` más allá de lo necesario**: sigue en un solo módulo (~40 líneas); separar el almacén en otro fichero tendría un solo uso.
10. **Riesgo alto**: ninguno. **Coste**: ~1 h de trabajo, 2 despachos de implementador + 2 revisiones de task + revisión final (orden de magnitud: pocos dólares en Sonnet).

**Goal**: las reservas persisten en `data/reservas.json` y se pueden listar (`salas reservas`) y cancelar (`salas cancelar <sala> <franja>`).

**Architecture**: `src/slots.js` carga el fichero JSON al inicio de cada operación y lo reescribe tras cada cambio; deja de tener estado en memoria. `bin/salas.js` añade los comandos `reservas` y `cancelar` y imprime la lista como líneas de texto en vez de JSON.

**Tech Stack**: Node ESM (`"type": "module"`), `node:fs`, `node --test`. Sin dependencias nuevas.

**Spec**: `./spec.md`

**Ejecución**: subagent, porque el dev-lead pidió parar antes de despachar el implementador de la Task 1.

`src/slots.js` (sustituye el array en memoria por carga/guardado):

```js
import { mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { dirname, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';

const SLOT = /^\d{2}-\d{2}$/;
const ROOMS = ['Norte', 'Sur'];
const DEFAULT_FILE = resolve(dirname(fileURLToPath(import.meta.url)), '../data/reservas.json');

const dataFile = () => process.env.SALAS_DATA ?? DEFAULT_FILE;

function load() {
  try {
    return JSON.parse(readFileSync(dataFile(), 'utf8'));
  } catch (error) {
    if (error.code === 'ENOENT') return [];
    throw error;
  }
}

function save(bookings) {
  mkdirSync(dirname(dataFile()), { recursive: true });
  writeFileSync(dataFile(), JSON.stringify(bookings, null, 2));
}

function checkSlot(slot) {
  if (!SLOT.test(slot)) throw new Error('Franja no válida: usa HH-HH, p. ej. 10-12');
}

export function reserve(room, slot) {
  checkSlot(slot);
  const bookings = load();
  if (bookings.some((b) => b.room === room && b.slot === slot)) throw new Error('Sala ocupada en esa franja');
  bookings.push({ room, slot });
  save(bookings);
  return { room, slot };
}

export function free(slot) {
  checkSlot(slot);
  const bookings = load();
  return ROOMS.filter((room) => !bookings.some((b) => b.room === room && b.slot === slot));
}

export function list() {
  return load().map((b) => `${b.room} ${b.slot}`);
}
```

`bin/salas.js`:

```js
#!/usr/bin/env node
import * as slots from '../src/slots.js';

const [command, ...args] = process.argv.slice(2);
const commands = {

} catch (error) {

}
```

```js
export function cancel(room, slot) {
  checkSlot(slot);
  const bookings = load();
  const index = bookings.findIndex((b) => b.room === room && b.slot === slot);
  if (index === -1) throw new Error(`No hay reserva de ${room} en ${slot}`);
  bookings.splice(index, 1);
  save(bookings);
  return { room, slot };
}
```
