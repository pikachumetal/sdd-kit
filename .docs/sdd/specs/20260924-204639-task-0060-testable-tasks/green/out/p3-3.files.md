# Plan de implementación — Salas favoritas

## Decisiones que he tomado yo — valida estas

1. **Ejecución: subagent** — 2 tasks con contrato compartido (forma de `GET /rooms`) y un repo cuya suite nadie ha visto en verde (decisión 6): una revisión independiente por task pesa más que el ahorro de Native. Alternativa: Native, más barato, sin revisión hasta el final.
2. **Modelo por task** — Task 1: `sdd-kit:effort-medium` + `sonnet` (atraviesa BD, API y web, hay que interpretar). Task 2: `sdd-kit:effort-low` + `sonnet` (el cambio de SQL va escrito en el plan y los RED ya lo cubren). Revisor final: `sdd-kit:effort-high` + `opus`. Sin `fable` ni `opus xhigh`.
3. **Corte en 2 tasks verticales**: T1 marcar, desmarcar y persistir, con su estrella; T2 orden con favoritas primero. Cada una acaba en algo que se prueba en la app.
4. **Contrato de API que la spec no fija**: `GET /rooms` devuelve `{id, name, seats, favorite}`; `PUT /rooms/:id/favorite` y `DELETE /rooms/:id/favorite` responden 204 y son idempotentes. Sin `X-User` → 400; sala inexistente en el `PUT` → 404. Cambia la salida observable de la API: si no lo quieres así, dilo antes de la Task 1.
5. **Identidad en la web (hueco de la spec)**: la web no tiene login y hoy no envía `X-User`. Asumo que lo lee de `localStorage['user']` (sin valor, la API responde 400 y la lista queda vacía). Es la decisión más frágil del plan y la lleva la Task 1: se valida antes de despacharla.
6. **Precondición (riesgo alto)**: faltan `api/db.js`, `api/tests/helpers.js`, `scripts/migrate.js` y el arranque de Express; `package.json` no declara `"type": "module"` y no hay `node_modules`. `npm test` ya falla hoy con `ERR_MODULE_NOT_FOUND`. No lo invento aquí porque amplía el Scope de la spec. Sin resolverlo, ningún RED falla por la razón correcta ni ningún verde se puede comprobar.
7. **Coste estimado**: ~3 h de implementación con la precondición resuelta; 2 implementadores, 2 revisores de task y el revisor final.

**Goal**: cada persona marca y desmarca salas favoritas con una estrella y las ve primero en la lista.

**Architecture**: tabla `favorite_rooms (user_name, room_id)`; `GET /rooms` hace `LEFT JOIN` con la persona de `X-User` y devuelve `favorite`; dos endpoints marcan y desmarcan; el componente pinta la estrella y recarga la lista tras cada cambio. El orden lo decide la API, la web pinta lo que recibe.

**Tech Stack**: Postgres (migraciones SQL numeradas), Express en `api/`, Angular en `web/`.

**Spec**: `./spec.md`

**Ejecución**: subagent, porque las 2 tasks comparten contrato y la revisión por task cubre un repo sin suite verificada.

`api/routes/rooms.js`:

```js
import { Router } from 'express';
import { db } from '../db.js';

export const rooms = Router();

rooms.use((req, res, next) =>
  req.get('X-User') ? next() : res.status(400).json({ error: 'Falta la cabecera X-User' }));

rooms.get('/rooms', async (req, res) => {
  const { rows } = await db.query(
    `SELECT r.id, r.name, r.seats, (f.room_id IS NOT NULL) AS favorite
       FROM rooms r
       LEFT JOIN favorite_rooms f ON f.room_id = r.id AND f.user_name = $1
      ORDER BY r.name`,
    [req.get('X-User')]);
  res.json(rows);
});

rooms.put('/rooms/:id/favorite', async (req, res) => {
  try {
    await db.query(
      'INSERT INTO favorite_rooms (user_name, room_id) VALUES ($1, $2) ON CONFLICT DO NOTHING',
      [req.get('X-User'), req.params.id]);
    res.sendStatus(204);
  } catch (error) {
    if (error.code === '23503') return res.sendStatus(404);
    throw error;
  }
});

rooms.delete('/rooms/:id/favorite', async (req, res) => {
  await db.query('DELETE FROM favorite_rooms WHERE user_name = $1 AND room_id = $2',
    [req.get('X-User'), req.params.id]);
  res.sendStatus(204);
});
```

`web/src/app/rooms/rooms.component.ts`:

```ts
import { Component, inject } from '@angular/core';
import { HttpClient, httpResource } from '@angular/common/http';

interface Room { id: number; name: string; seats: number; favorite: boolean }

@Component({ selector: 'app-rooms', templateUrl: './rooms.component.html' })
export class RoomsComponent {
  private readonly http = inject(HttpClient);
  private readonly headers = { 'X-User': localStorage.getItem('user') ?? '' };

  readonly rooms = httpResource<Room[]>(() => ({ url: '/api/rooms', headers: this.headers }));

  toggle(room: Room) {
    const url = `/api/rooms/${room.id}/favorite`;
    const request = room.favorite
      ? this.http.delete(url, { headers: this.headers })
      : this.http.put(url, null, { headers: this.headers });
    request.subscribe(() => this.rooms.reload());
  }
}
```

`web/src/app/rooms/rooms.component.html`:

```html

        (click)="toggle(room)">{{ room.favorite ? '★' : '☆' }}</button>

</ul>
```
