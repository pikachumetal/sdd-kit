# Plan de implementación — Salas favoritas

## Decisiones que he tomado yo — valida estas

1. **Ejecución Native, en la sesión** — son 2 tasks pequeñas que comparten el endpoint `GET /rooms` (la 2 solo cambia su `ORDER BY` y el refresco de la pantalla), y en esta sesión no hay herramienta para despachar subagentes. Un solo revisor final sobre la rama. Si prefieres subagentes, dilo antes de arrancar la task 1.
2. **Dos tasks verticales**: (1) marcar y desmarcar de punta a punta —tabla, API, estrella en pantalla—; (2) orden con las favoritas primero. Los seis THEN de la spec quedan repartidos así: listado, marcar y desmarcar en la 1; orden de Ana, orden de Luis y vuelta al orden original en la 2.
3. **Contrato de la API** (la spec no lo fija): `GET /rooms` añade `favorite: boolean` a cada sala; `PUT /rooms/:id/favorite` marca y `DELETE /rooms/:id/favorite` desmarca, ambos con `204`, idempotentes (marcar dos veces no falla).
4. **Sin `X-User`**: `GET /rooms` lista sin favoritas (como una persona que no tiene ninguna); `PUT` y `DELETE` responden `400`. Sala inexistente o `:id` no numérico en `PUT`/`DELETE`: `404`.
5. **Identidad en la web — provisional**: el frontend no envía hoy `X-User` y no hay login en esta fase. Dejo una constante `CURRENT_USER = 'ana'` en el componente que se manda como cabecera. Consecuencia: en la aplicación solo se puede probar como Ana; Luis se comprueba contra la API con `X-User: luis`. Si hay otra forma prevista de identificar a la persona en la web, cámbialo antes de la task 1.
6. **Riesgo alto — el repo no trae la infraestructura para ejecutar los tests**: faltan `api/db.js`, `api/tests/helpers.js`, `scripts/migrate.js`, `scripts/dev.js` y la configuración de Angular (`angular.json`), aunque `api/routes/rooms.js` y `rooms.test.js` los importan. Antes de escribir los RED comprobaré si `npm test` y `npm run test:web` arrancan; si no, es un freno y lo presento en lugar de inventar esa infraestructura.
7. **Modelo y effort**: las 2 tasks las hace el hilo principal con el modelo de la sesión (Native, sin despacho). Revisor final: `sdd-kit:effort-high` + `model: opus`.
8. **Coste estimado**: ~2 h de implementación y revisión; un revisor final, sin subagentes por task.

**Goal**: cada persona marca y desmarca salas como favoritas con una estrella, y las suyas salen primero en la lista.

**Architecture**: tabla `favorite_rooms (user_name, room_id)` con migración `002`; `GET /rooms` hace `LEFT JOIN` con las favoritas del `X-User` y ordena favoritas primero; `PUT`/`DELETE /rooms/:id/favorite` escriben la tabla. El componente `RoomsComponent` manda `X-User`, pinta una estrella por sala y recarga la lista tras cada cambio, de modo que el orden y el estado salen siempre del servidor.

**Tech Stack**: Postgres (migraciones SQL numeradas), Express en `api/` (`node:test`), Angular en `web/` (`httpResource`, `ng test`).

**Spec**: `./spec.md`

**Ejecución**: native, porque son 2 tasks pequeñas y acopladas por el mismo endpoint, y no hay herramienta de subagentes en esta sesión. `api/routes/rooms.js`:

```js
import { Router } from 'express';
import { db } from '../db.js';

export const rooms = Router();

rooms.get('/rooms', async (req, res) => {
  const { rows } = await db.query(
    `SELECT r.id, r.name, r.seats, f.room_id IS NOT NULL AS favorite
       FROM rooms r
       LEFT JOIN favorite_rooms f ON f.room_id = r.id AND f.user_name = $1
      ORDER BY r.name`,
    [req.get('X-User') ?? null],
  );
  res.json(rows);
});

rooms.put('/rooms/:id/favorite', async (req, res) => {
  const user = req.get('X-User');
  const id = Number(req.params.id);
  if (!user) return res.sendStatus(400);
  if (!Number.isInteger(id)) return res.sendStatus(404);
  try {
    await db.query(
      'INSERT INTO favorite_rooms (user_name, room_id) VALUES ($1, $2) ON CONFLICT DO NOTHING',
      [user, id],
    );
  } catch (e) {
    if (e.code === '23503') return res.sendStatus(404);
    throw e;
  }
  res.sendStatus(204);
});

rooms.delete('/rooms/:id/favorite', async (req, res) => {
  const user = req.get('X-User');
  const id = Number(req.params.id);
  if (!user) return res.sendStatus(400);
  if (!Number.isInteger(id)) return res.sendStatus(404);
  await db.query('DELETE FROM favorite_rooms WHERE user_name = $1 AND room_id = $2', [user, id]);
  res.sendStatus(204);
});
```

`web/src/app/rooms/rooms.component.ts`:

```ts
import { Component, inject } from '@angular/core';
import { HttpClient, httpResource } from '@angular/common/http';
import { firstValueFrom } from 'rxjs';

const CURRENT_USER = 'ana';
const headers = { 'X-User': CURRENT_USER };

interface Room { id: number; name: string; seats: number; favorite: boolean }

@Component({ selector: 'app-rooms', templateUrl: './rooms.component.html' })
export class RoomsComponent {
  private readonly http = inject(HttpClient);
  readonly rooms = httpResource<Room[]>(() => ({ url: '/api/rooms', headers }));

  async toggle(room: Room) {
    await firstValueFrom(
      this.http.request(room.favorite ? 'DELETE' : 'PUT', `/api/rooms/${room.id}/favorite`, { headers }),
    );
    this.rooms.reload();
  }
}
```
