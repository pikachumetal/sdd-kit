**Goal**: Cada persona marca y desmarca salas como favoritas con una estrella y las ve primero en la lista.

**Architecture**: Tabla `favorite_rooms` por persona (`X-User`); `GET /rooms` la cruza con un `LEFT JOIN` y ordena favoritas primero; dos rutas idempotentes escriben y borran filas. El componente pinta la estrella según `favorite` y llama a PUT o DELETE.

**Tech Stack**: Postgres (migraciones SQL numeradas), Express en `api/` (tests `node:test`), Angular en `web/` (`httpResource`).

**Spec**: `./spec.md`

**Ejecución**: subagent, porque el dev-lead nombró el despacho del implementador para esta task. Con dos tasks y un contrato de API compartido, la revisión por task acota el riesgo.

`api/routes/rooms.js`:

```js
import { Router } from 'express';
import { db } from '../db.js';

export const rooms = Router();

rooms.get('/rooms', async (req, res) => {
  const { rows } = await db.query(
    `SELECT r.id, r.name, r.seats, (f.room_id IS NOT NULL) AS favorite
       FROM rooms r
       LEFT JOIN favorite_rooms f ON f.room_id = r.id AND f.user_name = $1
      ORDER BY favorite DESC, r.name`,
    [req.get('X-User') ?? null],
  );
  res.json(rows);
});

async function withUserAndRoom(req, res, next) {
  const user = req.get('X-User');
  if (!user) return res.sendStatus(400);
  const { rowCount } = await db.query('SELECT 1 FROM rooms WHERE id = $1', [req.params.id]);
  if (!rowCount) return res.sendStatus(404);
  req.user = user;
  next();
}

rooms.put('/rooms/:id/favorite', withUserAndRoom, async (req, res) => {
  await db.query(
    'INSERT INTO favorite_rooms (user_name, room_id) VALUES ($1, $2) ON CONFLICT DO NOTHING',
    [req.user, req.params.id],
  );
  res.sendStatus(204);
});

rooms.delete('/rooms/:id/favorite', withUserAndRoom, async (req, res) => {
  await db.query('DELETE FROM favorite_rooms WHERE user_name = $1 AND room_id = $2', [
    req.user,
    req.params.id,
  ]);
  res.sendStatus(204);
});
```

```ts
import { Component, inject } from '@angular/core';
import { HttpClient, httpResource } from '@angular/common/http';

type Room = { id: number; name: string; seats: number; favorite: boolean };

@Component({ selector: 'app-rooms', templateUrl: './rooms.component.html' })
export class RoomsComponent {
  private readonly http = inject(HttpClient);
  readonly rooms = httpResource<Room[]>(() => '/api/rooms');

  toggleFavorite(room: Room) {
    const url = `/api/rooms/${room.id}/favorite`;
    const request = room.favorite ? this.http.delete(url) : this.http.put(url, null);
    request.subscribe(() => this.rooms.reload());
  }
}
```
