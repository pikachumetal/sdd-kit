# Patch 0013 — cancelar sin franja pide el uso

## 1. Síntoma

Fila de deuda técnica del roadmap (reproducido el 2026-09-10): `salas cancelar Norte` sin franja falla con `TypeError: Cannot read properties of undefined`; debería pedir el uso.

## 2. Causa raíz

El síntoma ya no reproduce en `develop`. `cancel` (`src/slots.js:5-8`) tiene desde `78cb468` («fix: cancelar sin franja pide el uso») un guard `if (!slot) throw new Error('Uso: salas cancelar <sala> <franja>')` antes de usar la franja. Reproducido con `cancel('Norte')`: lanza `Error: Uso: salas cancelar <sala> <franja>`, no `TypeError`.

Lo que faltaba es la cobertura: `tests/slots.test.js` solo probaba `reserve`, así que el guard no tenía ningún test y podía romperse sin aviso. La fila de deuda quedó abierta tras el fix por el mismo motivo: sin test ni rastro de patch, nada la cerraba.

## 3. Fix

- **Fichero(s)**: `tests/slots.test.js`
- **Cambio**: dos tests para `cancel`: sin franja lanza el mensaje de uso; con franja devuelve `{ cancelled: true }`. Sin cambio de código de producción, porque el guard ya existe.

## 4. Verificación

| # | Caso | Resultado |

| 2 | `node --test`: 3 pruebas, 3 OK | ✅ |

Limitación: no existe CLI en el repo (solo `src/slots.js`), así que no se pudo ejecutar `salas cancelar Norte` de extremo a extremo; se verificó la función `cancel`.
