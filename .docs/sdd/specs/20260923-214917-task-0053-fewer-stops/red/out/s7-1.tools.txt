# Patch 0013 — cancelar sin franja pide el uso

## 1. Síntoma

Fila de deuda técnica del roadmap (ticket de soporte 17): `salas cancelar Norte` sin franja
falla con `TypeError: Cannot read properties of undefined`; el comando revienta en vez de
pedir el uso.

## 2. Causa raíz

La hipótesis del ticket (`TypeError`) no se confirma. `cancel(room, slot)` en `src/slots.js`
no desreferencia `slot`, así que no lanza nada. Reproducido:

```
node -e "import('./src/slots.js').then(m=>console.log(m.cancel('Norte')))"
{ room: 'Norte', slot: undefined, cancelled: true }
```

El fallo real es peor que un error: `cancel` no valida `slot` y devuelve una cancelación
"válida" con `slot: undefined`. Un `TypeError` solo podría darse aguas abajo, en quien use ese
resultado; el repo no tiene CLI (`salas ...` no existe aún), así que ese punto no se ha podido
observar. Sin CLI, la validación en `cancel` es el único punto de control existente.

## 3. Fix

- **Fichero(s)**: `src/slots.js`, `tests/cancel.test.js`
- **Cambio**: `cancel` lanza `Error("Uso: salas cancelar <sala> <franja>")` si falta `slot`.
  Dos tests: sin franja lanza el uso; con franja sigue cancelando.
