# salas v1.3.0 — Reservas semanales y salas libres a un vistazo

*21 de septiembre de 2026*

## Resumen

Reservar una sala que necesitáis todas las semanas ya no obliga a repetir el trámite, y encontrar una sala libre en una franja concreta es inmediato. Además, cancelar una reserva deja de afectar a las de otros días.

## Novedades

- **Para quienes reservan salas con regularidad**: podéis dejar una reserva semanal y ahorraros volver a crearla cada semana.
- **Para quienes buscan sitio a última hora**: podéis consultar qué salas están libres en una franja horaria y elegir sin ir sala por sala.
- **Para quienes cancelan reservas**: al cancelar una reserva solo se cancela esa; ya no se borran las de otros días que coincidían en la hora.
