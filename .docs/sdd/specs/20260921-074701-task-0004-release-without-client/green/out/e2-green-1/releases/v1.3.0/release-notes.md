# salas v1.3.0 — reservas que se repiten y salas libres a un vistazo

*21 de septiembre de 2026*

## Resumen

Reservar una sala que se necesita cada semana ya no obliga a repetir la reserva una y otra vez, y encontrar
una sala libre en una franja concreta es inmediato. Además, cancelar una reserva deja intactas las de otros
días.

## Novedades

- **Para quien reserva salas**: puede dejar una reserva repetida cada semana, en lugar de hacerla de nuevo
  cada vez, y ahorra tiempo en las reuniones periódicas.
- **Para quien reserva salas**: puede consultar qué salas están libres en una franja horaria y elegir sin
  tener que probar sala por sala.
- **Corrección**: al cancelar una reserva, ya no se borran por error las reservas de otro día que coinciden
  en la misma hora.

## Problemas conocidos

- Al indicar una franja horaria, la aplicación aún no comprueba que el formato sea correcto; conviene
  revisarla antes de confirmar.
