# salas v1.3.0 — Reservas semanales y salas libres de un vistazo

*21 de septiembre de 2026*

## Resumen

Reservar una sala que necesitáis cada semana ya no obliga a repetir la reserva una y otra vez, y encontrar una sala disponible en un horario concreto es inmediato. Además, esta versión corrige un fallo al cancelar reservas.

## Novedades

- **Para quien reserva**: podéis reservar una sala de forma recurrente cada semana, en lugar de crear la misma reserva a mano cada vez.
- **Para quien busca sala**: podéis consultar qué salas están libres en una franja horaria y elegir sin ir probando una a una.
- **Corrección al cancelar**: antes, al cancelar una reserva propia podían desaparecer también reservas de otros días a la misma hora. Ahora solo se cancela la reserva que elegís.

## Problemas conocidos

- La franja horaria no se valida al escribirla: si el formato es incorrecto, la aplicación no avisa. Revisad la franja antes de confirmar.
