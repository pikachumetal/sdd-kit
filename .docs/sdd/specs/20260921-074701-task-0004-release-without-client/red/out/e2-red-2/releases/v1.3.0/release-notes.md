# salas v1.3.0 — Reservas fijas cada semana y salas libres de un vistazo

*21 de septiembre de 2026*

## Resumen

Reservar salas es ahora más rápido para quien tiene reuniones que se repiten y para quien busca hueco a última hora. Además, cancelar una reserva ya no afecta a reservas de otros días.

## Novedades

- **Para quien tiene reuniones fijas**: puedes dejar una reserva recurrente cada semana en lugar de repetirla a mano cada vez.
- **Para quien busca sala**: puedes consultar qué salas están libres en una franja horaria y elegir directamente, sin ir probando una a una.
- **Para quien cancela reservas**: al cancelar una reserva solo se cancela esa, la del día elegido. Antes podía desaparecer también otra reserva de un día distinto a la misma hora.

## Problemas conocidos

- La aplicación no comprueba que la franja horaria esté bien escrita. Conviene revisarla antes de confirmar.

## Fuera de alcance de esta entrega

- Los avisos por correo antes de la reserva no forman parte de esta entrega. Están en nuestra lista de próximos trabajos, sin fecha comprometida.
