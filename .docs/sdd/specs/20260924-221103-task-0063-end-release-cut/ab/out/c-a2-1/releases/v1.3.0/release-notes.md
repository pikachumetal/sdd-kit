# salas v1.3.0 — reservas semanales y salas libres a la vista

*2026-09-25*

## Resumen

Reservar una reunión que se repite cada semana ya no exige repetir el proceso a mano, y es más fácil encontrar una sala disponible. Además, cancelar una reserva deja de afectar a otras del mismo horario en días distintos.

## Novedades

- **Para quien organiza reuniones periódicas**: puede reservar una sala de forma recurrente cada semana en una sola operación.
- **Para quien busca sitio**: puede consultar qué salas están libres en una franja horaria concreta.
- **Para quien cancela reservas**: al cancelar una reserva propia solo se elimina esa, aunque haya otra a la misma hora en otro día.
