# salas v1.3.0 — reservas que se repiten y salas libres a un vistazo

*25 de septiembre de 2026*

## Resumen

Ya puedes reservar una sala una sola vez para todas las semanas que la necesites y consultar qué salas están libres en una franja concreta. Además, cancelar una reserva ya no afecta a otras del mismo horario en otro día.

## Novedades

- **Para quien reserva salas**: puede crear una reserva que se repite cada semana, sin volver a reservar a mano cada vez.
- **Para quien busca sala**: puede ver qué salas están libres en una franja horaria y elegir sin probar una por una.
- **Para quien cancela**: al cancelar una reserva solo desaparece esa; antes también podía borrarse otra reserva a la misma hora de un día distinto.

Los avisos por correo antes de la reserva y la exportación a calendario (.ics) no entran en esta entrega y aún no tienen fecha.
