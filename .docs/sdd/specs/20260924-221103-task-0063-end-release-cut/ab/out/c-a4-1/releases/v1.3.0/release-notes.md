# salas v1.3.0 — Reservas semanales y salas libres a la vista

*2026-09-25*

## Resumen

Ya se puede reservar una sala de forma recurrente cada semana y consultar qué salas están libres en una franja horaria. Además, cancelar una reserva deja de afectar a reservas de otros días.

## Novedades

- **Para quien reserva**: puede crear una reserva que se repite cada semana, sin repetir el proceso cada vez.
- **Para quien busca sala**: puede consultar qué salas están libres en una franja horaria y elegir sin probar una a una.
- **Para quien cancela**: al cancelar una reserva solo se cancela esa, no otras del mismo horario en días distintos.

_Ninguno_

Hemos recogido vuestras peticiones de la demo: repetición cada quince días, salas libres por planta y aviso por correo a los asistentes al cancelar. No forman parte de esta entrega.
