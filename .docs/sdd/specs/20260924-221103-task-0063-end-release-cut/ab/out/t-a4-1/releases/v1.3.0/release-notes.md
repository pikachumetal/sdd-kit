# Salas v1.3.0 — reservas que se repiten y salas libres a un vistazo

*25 de septiembre de 2026*

## Resumen

Reservar una sala de forma recurrente ya no obliga a repetir el trámite cada semana, y encontrar una sala libre en una franja concreta es inmediato. Además, cancelar una reserva ya no afecta a otras.

## Novedades

- **Para quien reserva salas**: puede dejar una reserva repetida cada semana y se ahorra volver a reservar la misma sala una y otra vez.
- **Para quien busca sala**: puede consultar qué salas están libres en una franja horaria y elegir sin probar una a una.
- **Para quien cancela**: al cancelar una reserva solo se elimina la del día elegido; las reservas de otros días a la misma hora se mantienen.
