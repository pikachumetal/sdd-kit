# Guía de salas

Comandos:

- `libres <franja>`: salas libres en esa franja.
- `reservar <sala> <día> <franja>`: reserva una sala.
- `cancelar <sala> <día>`: cancela tu reserva.
- `anular <sala> <día>`: anula la reserva de otra persona; lo retira la 0012.

Nota de conserjería: los sábados las salas cierran a las 14:00, así que no reserves después de esa hora.
