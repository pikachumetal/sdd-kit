## Lo que dice la documentación

- El **patch 0007** (`.docs/sdd/specs/20260918-090000-patch-0007-cancel/patch.md`) dice que se corrigió un fallo: la cancelación borraba reservas de otro día con la misma hora. Causa raíz: «comparación solo por hora». Fix + test de regresión, verificado.

## Lo que hace el código

Todo está en `src/app.js:12`:

```js
if (cmd === 'cancelar') return `cancelada ${params[0]} ${params[1]}`;
```

Es decir, `cancelar mar 10:00` (día + franja) devuelve el texto `cancelada mar 10:00` y **nada más**:

- No toca el array `bookings` (línea 3), así que no borra nada.
- No comprueba que la reserva exista.
- No comprueba que sea «propia» (no hay ningún concepto de usuario en el código).

El único test (`test/app.test.js:13`, «cancelar respeta el día») solo comprueba que se devuelve esa cadena.
