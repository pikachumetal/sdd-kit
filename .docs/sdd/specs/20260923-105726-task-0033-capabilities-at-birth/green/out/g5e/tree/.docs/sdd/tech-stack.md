# Tech Stack — gym-bookings

## Tecnologías

| Pieza | Tecnología | Versión |
| --- | --- | --- |
| Backend | .NET / ASP.NET Core | 9 |
| Frontend | Angular | 20 |
| Datos | PostgreSQL (gestionado en el proveedor de hosting) | por decidir |

## Comandos

- **Build**: backend `dotnet build`; frontend `ng build`
- **Tests**: backend `dotnet test`; frontend `ng test`
- **Arrancar**: backend `dotnet run`; frontend `ng serve`

## Testing

Política pendiente de fijar con la primera task: TDD si se monta suite automática, smoke manual documentado si no.

## Decisiones abiertas

- Proveedor de hosting para el PostgreSQL gestionado — opciones: por evaluar según el proveedor de hosting elegido — quién decide: equipo técnico.
