# Capacidad — search

Localización de notas dentro de Horizon Notes: por ahora, filtrado por etiqueta.

## Requisitos

### Filtro por etiqueta

GIVEN una colección de notas con etiquetas
WHEN se elige una etiqueta para filtrar
THEN se muestran solo las notas que contienen esa etiqueta

### Filtro vacío muestra todas las notas

GIVEN que no hay ninguna etiqueta seleccionada
WHEN se abre la vista de notas
THEN se muestran todas las notas sin filtrar
