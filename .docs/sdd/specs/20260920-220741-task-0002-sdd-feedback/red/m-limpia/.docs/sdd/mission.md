# Misión — Horizon Notes

## Por qué existe

Horizon Notes es una herramienta personal de notas en Markdown para un único usuario: yo mismo
como desarrollador y único usuario. Nace porque las apps de notas que probé o eran demasiado
pesadas o guardaban el texto en un formato propietario que no podía versionar con git. Horizon
Notes guarda cada nota como un fichero `.md` plano en disco.

## Usuario

Un único usuario: el propio desarrollador. No hay cuentas, no hay multiusuario.

## Glosario

- **Nota**: fichero `.md` individual con un título (primera línea `# `) y cero o más etiquetas.
- **Etiqueta**: palabra precedida de `#` dentro del cuerpo de la nota, usada para filtrar.
- **Filtro por etiqueta**: vista que muestra solo las notas que contienen una etiqueta dada.
