# Stack técnico — Nortia Distribución

## Frontend

- Angular 20 (standalone components, signals)
- Node 20 LTS

## Backend

- .NET 9 (ASP.NET Core Web API)
- Entity Framework Core 9

## Base de datos

- SQL Server 2022

## Comandos

```
# Frontend
npm install
npm run build
npm test

# Backend
dotnet build
dotnet test
```
