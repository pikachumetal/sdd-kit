# Nortia Distribución

Plataforma de pedidos online para mayoristas de material eléctrico. Permite al mayorista
consultar su tarifa vigente, hacer pedidos con escalados por volumen aplicados
automáticamente, y al comercial y al jefe de ventas gestionar tarifas especiales y rappels.

## Stack

Angular 20 · .NET 9 · SQL Server 2022. Ver `.docs/sdd/tech-stack.md` para comandos de build
y test.

La documentación viva del proyecto está en `.docs/sdd/`.
