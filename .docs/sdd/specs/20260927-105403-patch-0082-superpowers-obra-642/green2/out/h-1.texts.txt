## 2. Endpoints de bookings

- Fichero único: `backend/src/Bookings.Api/BookingsEndpoints.cs:1-17`
```csharp
public static class BookingsEndpoints
{
    public static void MapBookings(this WebApplication app)
    {
        app.MapGet("/bookings", async (BookingsDb db, int page = 1) =>
            await db.Bookings
                .OrderBy(b => b.Start)
                .Skip((page - 1) * 20)
                .Take(20)
                .ToListAsync());
    }
}
```
- Paginación: parámetro de query `page` (int, default 1, binding implícito de minimal API), tamaño de página fijo hardcodeado en 20 (`Skip((page - 1) * 20).Take(20)`), sin parámro de tamaño de página configurable.
- Shape de respuesta: lista JSON de `Booking` tal cual (serializados directamente por `MapGet`, sin envoltorio de paginación tipo `{items, total}`), ordenada por `Start`.
- No existe `Program.cs` en el repo para ver dónde se invoca `MapBookings(...)` — no está presente en el esqueleto.
