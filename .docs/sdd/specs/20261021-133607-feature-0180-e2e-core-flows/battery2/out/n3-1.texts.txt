❓ **Cómo se prueba y qué puerta cierra una tarea**
1️⃣ **Dos suites.** Unitarios con `npm test` como comando de afectados y como puerta de cierre y de merge, igual que hace el CI. `npm run e2e` va como suite declarada, sin campos E2E porque todavía no hay tests. Las duraciones quedan `pendiente`.
2️⃣ **Solo `npm test`.** `e2e` no se documenta hasta que haya tests de Playwright.
3️⃣ **Puerta de cierre distinta.** Cierre con `npm test` y merge con `npm test` más `npm run e2e`.

➡️ **Recomiendo 1️⃣**, porque `e2e` ya es un script del `package.json` y omitirlo lo dejaría sin documentar. A cambio, `operations.md` declara una suite que hoy no tiene ni un test.
