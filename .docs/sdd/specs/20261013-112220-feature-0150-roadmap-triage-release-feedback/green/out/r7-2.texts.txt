## La deuda: sin validación del formato de franja horaria

**Reproducida.** Una franja inválida no da error, devuelve todas las salas como libres:

```
$ node src/app.js libres "basura"
Norte, Sur
$ node src/app.js libres "25:99-xx"
Norte, Sur
$ node src/app.js libres "10:00-12:00"      # franja válida y reservada, para contraste
Sur
```

Con la evidencia en la mano, la fila no se queda en espera ni se descarta. Mi propuesta es **Actuar**. No inventa reservas, pero hace que `libres` informe de disponibilidad que no existe: quien se equiba al teclear ve las dos salas libres.
