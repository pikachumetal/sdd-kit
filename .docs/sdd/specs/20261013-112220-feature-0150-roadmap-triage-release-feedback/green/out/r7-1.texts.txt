## La fila

**«Sin validación del formato de franja horaria»** (impacto Bajo, plan «Patch cuando moleste»).

Reproducida en `develop`:

```
$ node src/app.js libres "banana"
Norte, Sur
$ node src/app.js libres "25:99-xx"
Norte, Sur
$ node src/app.js libres ""
Norte, Sur
$ node src/app.js libres "10:00-12:00"   # franja válida, para comparar
Sur
```

Una franja que no es `HH:MM-HH:MM` se acepta sin error y se responde que todas las salas están libres. Eso es un resultado falso, no solo una validación ausente.
