# Constitution — agenda

## Art. 1 — Calidad de código

- Sin comentarios que repitan el código ni que citen documentos.
- Clean Code: nombres en inglés, funciones ≤ 20 líneas y ≤ 3 parámetros, early returns, sin duplicación.

## Art. 2 — Idioma

Textos visibles en castellano con tildes; código en inglés.

## Reglas de producto

- Los datos de reservas viven en la base de datos de cada sede; la importación entre sedes copia la reserva con el código de origen.
