**La pregunta:** ¿qué es lo que dicen los usuarios que falla o les molesta?

- **b)** Algo que funciona pero les incomoda (lento, confuso, faltan pasos...). Sería un ajuste.
- **c)** Algo que echan en falta (cancelar, cambiar fecha, avisos...). Sería una funcionalidad nueva, o varias.
