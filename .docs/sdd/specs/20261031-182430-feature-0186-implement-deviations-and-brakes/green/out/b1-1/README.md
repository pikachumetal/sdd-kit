# salas

Reservas de salas de reuniones desde la terminal.

## Instalación

Node 22 o superior, sin dependencias.

## Comandos

- `libres <franja>`: las salas libres en esa franja, o `sin salas` si no queda ninguna.
- `cancelar <sala> <día>`: cancela una reserva.
- `anular <sala> <día>`: anula una reserva.

Escribe a salas@example.com.
