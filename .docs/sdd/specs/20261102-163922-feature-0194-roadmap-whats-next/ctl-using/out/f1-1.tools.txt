**Preguntas, en este orden:**

1. **Carril.**
   1. Lite (recomendada): spec corta, sin `plan.md`, y tú validas la spec.
   2. Feature en modo full: spec y plan completos.
2. **Sintaxis del filtro.**
   1. `libres <franja> --sala Norte` (recomendada): sigue el estilo de `--cada-semana` y deja `<franja>` como primer argumento.
   2. `libres <franja> Norte`: posicional, más corto, pero ambiguo si más adelante añades otro parámetro.
3. **Resultado con filtro.**
   1. Si la sala está libre, devuelve `Norte`. Si está ocupada, devuelve `sin salas libres`. Una sala que no existe devuelve `sala desconocida: X` (recomendada).
   2. Si la sala está ocupada devuelve cadena vacía, y la desconocida también.
