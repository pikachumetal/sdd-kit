Proyecto de reservas de salas (.NET 9 + EF Core 9 sobre SQL Server para el backend; Angular 20 en el frontend, que no toca esta task). La spec pide filtrar la lista de reservas por estado. La Task 2 (otro implementador, después) consumirá tu endpoint desde el frontend esperando `status` como texto (`Confirmed`, `Pending`, `Cancelled`) en el JSON de cada `Booking`.
