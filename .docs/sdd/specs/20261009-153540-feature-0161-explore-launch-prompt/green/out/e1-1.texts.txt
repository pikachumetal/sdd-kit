Las reservas se cancelan en el comando `cancelar`, en `src/app.js:12`:

```js
if (cmd === 'cancelar') return `cancelada ${params[0]} ${params[1]}`;
```

Se invoca como `cancelar <día> <hora>`, por ejemplo `cancelar mar 10:00`, y lo cubre `test/app.test.js:13` («cancelar respeta el día»).

Lo que dicen los docs y lo que infiero del código:

- **Docs:** el patch 0007 (`.docs/sdd/specs/20260918-090000-patch-0007-cancel/patch.md`) corrigió que la cancelación borraba reservas de otro día con la misma hora. La causa era comparar solo por hora. El changelog también lo recoge.
- **Código, lo que infiero:** ahora mismo `cancelar` no borra nada. Solo devuelve el texto `cancelada <día> <hora>` y no toca el array `bookings`. El test solo comprueba ese texto, así que no verifica que se borre la reserva.
- **Posible desajuste:** el changelog dice «Cancelar una reserva propia», pero el código no tiene noción de propietario. No hay ningún campo de usuario en `bookings`.

Si quieres corregir que `cancelar` borre de verdad la reserva, eso ya es un cambio y pasaría por `sdd-propose`.
