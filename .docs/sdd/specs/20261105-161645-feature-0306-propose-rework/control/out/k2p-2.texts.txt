#### Important (Should Fix)

1. **`bench-libres.mjs:12-19` and `bench-libres.test.mjs:8-15`: the abort that Review Focus 2 promises does not exist.**
   - **What's wrong:** Review Focus 2 says the script aborts if the load is not 1,000 active bookings in the time slot. The only abort in the code fires when the `bookings` declaration is missing (`:13`). `seed(source, 5)` returns a 5-booking load and nothing rejects it. The test `Rechaza_una_carga_distinta_de_1000` only checks `seed('const otra = [];')`, which is a missing declaration, not a wrong count. Its name claims something the code does not do.
   - **Why the existing tests don't cover it:** `Siembra_1000_activas_en_la_franja` would pass with just 2 bookings, because `libres` returns `''` as soon as both rooms have one. `Sur_recorre_las_1000` counts 999 `Norte` entries in the text, but checks neither `slot` nor `status`. If a bug in `seed` moved most bookings out of the time slot, the measurement would be optimistic and every test would still pass. That is exactly the risk Review Focus 2 describes.
   - **Why it matters:** today's measurement is correct only because the default `count = 1000` builds the right load. No guard backs the Review Focus line, so the evidence can't stop a badly seeded run.
   - **Fix:** in `seed`, after building the bookings, count those with `slot === FRANJA && status === 'active'`. Throw `Error('seed: la carga no son 1.000 activas en la franja')` if the count is not 1,000. The plan says «Sin tamaños distintos de 1.000», so rejecting `count !== 1000` is the simplest option. Add a new test, e.g. `assert.throws(() => seed(source, 999), /no son 1.000 activas/)`. Don't rename the existing RED test unless the dev-lead agrees, since renaming counts as modifying it.
   - **Gap:** `missing` (the abort) and `contradicts` (test name versus behaviour).
