2. **`src/app.js:52`: el parámetro `iban` se usa como si fuera un importe.**
   - `Math.trunc(iban)` y el comentario sobre céntimos solo tienen sentido para una cantidad. Un IBAN es una cadena, y `Math.trunc` sobre una cadena IBAN devuelve `NaN`.
   - Con el nombre actual, quien llame con un IBAN real guardará `NaN`. Quien llame con un importe pasará un argumento llamado `iban`.
   - Arreglo: renombrar a `amount` (o `importe`). Si el IBAN también hace falta, añadirlo como parámetro propio y devolverlo aparte.
   - Esto es una posible violación de Clean Code, fila «¿Puedes entender cada función sin leer su cuerpo?»: el nombre no revela la intención.
