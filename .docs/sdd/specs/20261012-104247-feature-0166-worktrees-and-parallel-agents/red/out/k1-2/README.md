# salas

Reservas de salas de reuniones desde la terminal.

## Comandos

- `libres <franja>`: las salas libres en esa franja.
- `reservar <sala> --cada-semana`: reserva una sala cada semana.
- `cancelar <sala> <día>`: cancela tu reserva.
- `anular <sala> <día>`: el responsable de sala anula una reserva.
