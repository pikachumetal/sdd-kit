## 2. Contenido de `code-reviewer.md`

Es la plantilla para dispatchar un subagente "Senior Code Reviewer". Estructura del prompt que se le da:
- Contexto: `[DESCRIPTION]` (qué se implementó) y `[PLAN_OR_REQUIREMENTS]`.
- Rango git a revisar con `[BASE_SHA]`/`[HEAD_SHA]` y comandos `git diff --stat` / `git diff`.
- **"The spec is a vision document"**: juzgar por lo que un usuario razonable esperaría, no solo lo que el spec enumera explícitamente.
- **"Declined to judge"**: listar comportamientos descartados por estar fuera del plan, con motivo, antes del veredicto.
- **"Read-Only Review"**: prohibido mutar el working tree/index/HEAD; usar `git show/diff/log`, y si necesita otra revisión usar `git worktree add` en directorio temporal aparte.
- **"You Do Not Dispatch Subagents"**: el revisor debe hacer todo el trabajo él mismo, nunca delegar en subagentes.
- Checklist: alineación con el plan, calidad de código, arquitectura, testing, production readiness.
- Calibración de severidad (no todo es Critical), reconocer aciertos antes de listar problemas.
- Formato de salida fijo: Strengths / Issues (Critical, Important, Minor con file:line) / Recommendations / Assessment (veredicto Ready to merge: Yes/No/With fixes + razonamiento).
- Reglas DO/DON'T finales (ser específico, explicar el porqué, no decir "se ve bien" sin comprobar, etc.).
- Incluye placeholders y un ejemplo de salida completo.

## 3. `review-package` (script)

Bash script (`review-package PLAN_FILE BASE HEAD [OUTFILE]`) que genera el paquete de revisión: valida BASE/HEAD como commits válidos y que HEAD desciende de BASE (rango no vacío), y escribe en `OUTFILE` (o ruta por defecto) el bloque `## Commits` (`git log --oneline`), `## Files changed` (`git diff --stat`) y `## Diff` (`git diff -U10`).

Si no se pasa `OUTFILE`, la ruta por defecto se calcula invocando el script hermano `sdd-workspace` con el plan, y queda como:
`<repo-root>/.superpowers/sdd/<plan-basename>/review-<base7>..<head7>.diff`

Al terminar imprime la ruta con:
```
echo "wrote ${out}: ${commits} commit(s), $(wc -c < "$out" | tr -d ' ') bytes"
```
es decir, imprime literalmente `wrote <ruta_del_paquete>: N commit(s), M bytes` por stdout.
