Las reservas se cancelan en `src/app.js:12`, dentro de `run()`:

```js
if (cmd === 'cancelar') return `cancelada ${params[0]} ${params[1]}`;
```

Eso es lo que hace el código, y lo que dicen los documentos es distinto. Esa línea solo devuelve un texto con el día y la hora que recibe, por ejemplo `cancelada mar 10:00`. No toca el array `bookings` (línea 3), así que en realidad no borra nada.

- **Test:** `test/app.test.js:13` ("cancelar respeta el día") solo comprueba ese texto.
