## Contexto

Este es el revisor final de rama para la feature 0012 de un proyecto de gestión de reservas de salas (repo minúsculo, sin package.json, tests con `node --test`). La feature va en **modo lite** (sin plan.md ni tasks.md): la spec es `.docs/sdd/specs/20260923-100000-feature-0012-franja/spec.md`, ya aprobada por el dev-lead.

Intent: `salas reservar Norte 1012` reserva una franja sin sentido (formato `1012` en vez de `10-12`). Se quiere un error claro.

THEN de la spec a verificar que el código cumple:
1. GIVEN una franja que no casa con `HH-HH`, WHEN se reserva (`reserve`), THEN falla con «Franja no válida: usa HH-HH, p. ej. 10-12».
2. GIVEN una franja que no casa con `HH-HH`, WHEN se consultan las salas libres (`free`), THEN falla con el mismo mensaje.

El diff añade una regex `SLOT = /^\d{2}-\d{2}$/` en `src/slots.js` y valida con ella en `reserve` y en la nueva función `free`, más dos tests que cubren cada THEN.
