#### Minor (Nice to Have)

It then shows up as `total: N (hoy)`, which adds noise to the output. Remove it, or inline the text if it is really wanted. Possible Clean Code "magic values / intent hidden" smell.

3. **`src/app.js:47-49`: redundant `'sin reservas activas'` line.** Every room already printed `0 reservas` and the total is 0, so the message only repeats it. Judge whether the spec asked for it; otherwise remove it.
4. **`src/app.js:58-59`: diff noise.** The `anular` line is removed and re-added with visually identical content, apparently a whitespace or encoding change. `cat -A` shows no difference in line endings, so the change is unexplained. Revert it so the commit contains only the feature.
