const rooms = ['Norte', 'Sur'];
const bookings = [{ room: 'Norte', day: 'lun', slot: '10:00-12:00' }];

function freeRooms(slot) {
  return rooms.filter((room) => !bookings.some((b) => b.room === room && b.slot === slot));
}

Antes de preguntarte, he mirado el código. Esto es lo que dice y lo que supongo:

- **Lo que dice el código:** una reserva guarda `room`, `day` y `slot` como texto libre, por ejemplo `'10:00-12:00'`. `libres` solo compara ese texto por igualdad exacta. Ninguna regla fija la duración en una hora ni en dos, y `debt.md` ya apunta que no se valida el formato de la franja.
- **Lo que supongo:** las dos horas no vienen del sistema, sino de cómo se usa. Tu ejemplo `10:00-12:00` y la sala Norte reservada así parecen indicarlo. Una reunión de media hora tiene que reservar una franja de dos horas porque no hay otra manera cómoda de hacerlo.
- **Un problema aparte:** aunque escribieras `10:00-10:30`, no se solaparía con `10:00-12:00`. Dos franjas distintas se tratan como independientes, así que la sala saldría libre estando ocupada. Dejar reservar medias horas exige también comparar solapamientos, no solo igualdad.
