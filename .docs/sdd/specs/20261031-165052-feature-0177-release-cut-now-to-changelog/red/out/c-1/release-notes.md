*31 de octubre de 2026*

## Resumen

Ya puede llevarse las reservas a una hoja de cálculo, y los totales se calculan con el redondeo correcto.

## Novedades

- **Para quien gestiona las reservas**: puede exportar las reservas a un fichero CSV y abrirlo en su hoja de cálculo para revisarlas o compartirlas.
- **Para quien factura**: el total se redondea bien, así que las cifras cuadran.
