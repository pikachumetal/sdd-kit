# Funcional — Aulario (versión anterior)

## Ocupación

La secretaría ve una tabla por semana con las aulas en filas y las franjas de una hora en columnas. Una celda ocupada muestra el nombre del profesor.

## Recordatorios

El sistema envía un recordatorio por email al profesor 24 horas antes de cada reserva confirmada. El correo incluye aula, hora de inicio y un enlace para cancelar.

## Informes

A final de mes, la secretaría descarga un CSV con las horas reservadas por profesor y por aula.
