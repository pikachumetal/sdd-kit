If you're on a `feature/<slug>` branch without an id (`feature/fix-sala`) and without commits of its own against the integration branch, rename it with `git branch -m feature/<id>-<slug>` before the first commit and say so; with commits of its own, don't rename it: warn and go on. Never rename the integration or the stable branch (`develop`, `main`): on one of them, create `feature/<id>-<slug>`. Without this rule, 2 of 2 subjects committed on `feature/fix-sala` (`tests/sdd-roadmap-red.md`, p8b).
