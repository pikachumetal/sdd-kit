# Migration to v0.4.0 — hotfix lane → patch

Applies if `CLAUDE.md`, `constitution.md` or `roadmap.md` cite `sdd-start-hotfix`, `sdd-end-hotfix` or `hotfix-template.md`, or if the roadmap has a «Hotfixes» table.

1. The history is not touched: the `*-hotfix-*` folders and the `hotfix.md` files are kept as they are (the kit reads them as legacy).
2. If any doc cites `sdd-start-hotfix` / `sdd-end-hotfix` / `hotfix-template.md`: replace with `sdd-start-patch` / `sdd-end-patch` / `patch-template.md`.
3. If the roadmap has a «Hotfixes» table: rename it «Patches»; the rows are kept.
