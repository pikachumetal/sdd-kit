# El roadmap como única fuente del scope — detalle

5. **Roadmap como única fuente** — sección "Release N" con filas trazables al acta/origen. **No crear
   documentos paralelos de scope** (`scope.md`, snapshots): duplicar el roadmap es fabricar deriva; git ya
   versiona los cambios de alcance. **Los ids no se inventan**: el origen legítimo es el gestor del proyecto
   o la secuencia (`.docs/sdd/sdd-kit.json`, `ids.mode: sequence` + `Get-NextSddId.ps1 -Reserve`); elegir un número a
   ojo sigue prohibido.
