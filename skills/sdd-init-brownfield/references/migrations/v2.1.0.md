# Migración a v2.1.0 — sin cambios en el proyecto

La release 2.1.0 del kit no cambia nada del proyecto: sin cambios en el proyecto. Esta migración solo avanza el marcador, para que `.docs/sdd/sdd-kit.json` diga la versión del kit que el proyecto tiene aplicada.

1. **Marcador.** Escribir en `.docs/sdd/sdd-kit.json` `"version": "2.1.0"`, el `channel` (`plugin` o `cli`) y `"updated": "<hoy>"`, fusionando: las demás claves se quedan como están.

**Escribe**: `sdd-kit.json` → `version`, `channel`, `updated`.

## Verificación

- `.docs/sdd/sdd-kit.json` declara `"version": "2.1.0"` y conserva el resto de sus claves.
- `git diff --stat HEAD~1` de la migración solo lista `.docs/sdd/sdd-kit.json`.
