# Migración a v1.1.0 — nombres de fichero en inglés

Solo aplica a proyectos que ya aplicaron v1.0.0 con los nombres antiguos. Un proyecto que migre a v1.0.0 con el kit actual ya recibe los nombres correctos y aquí no encontrará nada que hacer: todos los pasos se saltan por predicado.

1. **`funcional/` → `capabilities/`.** Si existe `.docs/sdd/funcional/`: **gate** — `git mv .docs/sdd/funcional .docs/sdd/capabilities`.
2. **`legado.md` → `legacy.md`.** Si existe `.docs/sdd/capabilities/legado.md`: `git mv .docs/sdd/capabilities/legado.md .docs/sdd/capabilities/legacy.md`. En la nota de excepción del principio del fichero, sustituir `legado` por `legacy` y `funcional/<capacidad>.md` por `capabilities/<capability>.md`.
3. **Capacidades con nombre en castellano.** Si algún fichero de `.docs/sdd/capabilities/` tiene el nombre en castellano: **gate** — presentar la lista con el nombre inglés kebab-case propuesto para cada uno y esperar al dev-lead. Los nombres los decide él: una capacidad es un sustantivo del dominio de **su** proyecto, y el kit no lo conoce. El título interno `# Capacidad — <nombre>` de cada fichero acompaña al nombre nuevo.
4. **`changelog-cliente.md` → `client-changelog.md`.** Si existe `.docs/sdd/changelog-cliente.md`: `git mv .docs/sdd/changelog-cliente.md .docs/sdd/client-changelog.md`.
5. **Referencias.** Sustituir en `CLAUDE.md` y en los documentos de anclaje vivos de `.docs/sdd/` (`mission.md`, `constitution.md`, `architecture.md`, `tech-stack.md`, `estimation.md`): `funcional/` → `capabilities/`, `funcional/<capacidad>.md` → `capabilities/<capability>.md`, `changelog-cliente` → `client-changelog`. **No** se tocan `changelog.md`, `roadmap.md`, `releases/` ni `specs/`: describen lo que ya se entregó y reescribirlos falsearía el histórico.
6. **Marcador.** Escribir `.docs/sdd/sdd-kit.json`: `{ "version": "1.1.0", "channel": "plugin" | "cli", "updated": "<hoy>" }`.

## Verificación

- `Test-Path .docs/sdd/funcional` → `False`; `Test-Path .docs/sdd/changelog-cliente.md` → `False`.
- `Get-ChildItem .docs/sdd/capabilities` → ningún nombre en castellano; si había legado, ahora es `legacy.md`.
- `grep -rn "funcional/\|changelog-cliente" CLAUDE.md .docs/sdd/*.md` → sin resultados.
- `git log --diff-filter=M --name-only -1 -- .docs/sdd/changelog.md` no muestra esta migración: el changelog sellado no se tocó.
- `.docs/sdd/sdd-kit.json` existe con `"version": "1.1.0"`.
