# Target structure — the kit fixes it, it isn't redesigned

```text
/
├── PRODUCT.md                (traces PRODUCT-template.md)
├── ROADMAP.md                (traces now-next-later-template.md)
├── CHANGELOG.md              (optional, per the interview · traces changelog-template.md)
├── CLAUDE.md                 (short: pointers + 3-5 critical rules; through its gate)
├── .claude/settings.json     (written by `sdd init --finish`, merged with what it already has)
├── .gitignore                (+ .playwright-mcp/, .superpowers/, .docs/sdd/sdd-kit.local.json; by `sdd init --finish`)
└── .docs/
    └── sdd/
        ├── steering/
        │   ├── constitution.md     (traces constitution-template.md)
        │   ├── operations.md       (traces operations-template.md)
        │   ├── architecture.md     (traces architecture-template.md)
        │   ├── debt.md             (with code: the inventory's debt in «Por triar» · traces debt-template.md)
        │   ├── estimation.md       (method, empty calibration · traces estimation-template.md)
        │   └── estimation-log.md   (generated by `sdd estimation log`: header and 0 rows)
        ├── sdd-kit.json            (`init` while the init runs; at the end { "version", "channel": "plugin", "updated", "ids", "control"?, "merge"?, "execution"?, "validation"? })
        ├── sources/                (optional: the functional brief the user brings, verbatim)
        ├── capabilities/           (not created: born with the first feature that declares one, or with the dump of step 8)
        ├── decisions/              (not created: born with the first ADR)
        └── changes/                (not created: born with the first feature or patch)
```

Git doesn't version empty folders: no folder of `.docs/sdd/` is created empty or with `.gitkeep`.

No `templates/` folder: the templates live in the kit's `sdd-templates` skill and are traced when each document is created. **Tracing** is following the template's sections and table headers with the interview's content; never copying the equivalent document from the kit's `.docs/` or another project's, which drags in other people's notes and decisions.

A 2.x template (`mission.md`, `tech-stack.md`, `roadmap.md`) keeps its shape; the migration moves it. The domain's language lives in `## Terminology` of `PRODUCT.md`, a rule in the constitution, the why of a rule in an ADR of `decisions/`.
